# Правила проекта

## Оформление текста

- Не использовать длинное тире (em dash, U+2014). Вместо него ставить обычный дефис "-".
- То же для короткого тире (en dash, U+2013): в диапазонах писать дефис, например "2023-2024" и "P1-P4".
- Правило действует для всех текстов проекта: документы, комментарии в коде, сообщения коммитов, тексты интерфейса и ответы в чате.
