# Smartup Hub

Портал клиентов Smartup: обращения в поддержку, база решений, идеи по продукту. Адрес: `hub.smartup24.com`.

Состояние: веха M0 (основа проекта). Порядок вех и что уже сделано: `docs/plans/README.md`.

## Что нужно

- Node.js 26 (точная версия в `.node-version`)
- pnpm 12 (версия в `package.json`)
- Docker с Compose

## Команды

| Команда | Что делает |
|---|---|
| `pnpm install` | Ставит зависимости |
| `pnpm dev` | Запускает приложение для разработки |
| `pnpm build` | Собирает приложение |
| `pnpm start` | Запускает собранное приложение |
| `pnpm check` | Типы, линтер и проверки проекта |
| `pnpm test` | Модульные тесты |
| `pnpm test:integration` | Тесты с базой данных |
