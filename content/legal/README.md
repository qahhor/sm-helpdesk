# Тексты политики обработки данных

Отсюда портал берёт политику обработки данных (раздел 14.6 ТЗ, решение 0017). Пока в каталоге нет файла `manifest.json`, политика выключена: страницы `/{язык}/legal/privacy` нет (ответ 404), строки о политике на страницах входа и в шаге первого входа нет.

## Как включить

1. Юрист утверждает текст. Черновик для него: `docs/legal/privacy-draft.ru.md`.
2. Положите сюда утверждённые тексты: `privacy.ru.md`, `privacy.uz.md`, `privacy.en.md`. Русский обязателен: им заменяется перевод, которого нет.
3. Положите `manifest.json` с датой редакции:

   ```json
   { "privacy": { "version": "2026-12-01" } }
   ```

4. Разверните портал. Пользователи увидят строку о политике в шаге первого входа. Новая дата в `manifest.json` означает новую редакцию: каждый пользователь при следующем входе увидит короткий шаг о ней.

## Формат текста

- Строка с `# ` в начале: заголовок документа.
- Строка с `## `: заголовок раздела.
- Строка с `- `: пункт списка.
- Остальное: абзацы. Соседние строки абзаца склеиваются, пустая строка начинает новый абзац.

Разметка HTML и ссылки не разбираются: всё выводится как обычный текст. Длинное и среднее тире в текстах не используются (проверка `pnpm check`).
