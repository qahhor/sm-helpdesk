FR-ID-14, разделы 9.1, 12.2, 13.5, 14.5, 14.6, 15.3, веха M4b в разделе 16.2. Вопрос 42 закрыт. Этими же правками решения 89 и 90 донесены до разделов схемы, точек входа, переменных, ограничений частоты и персональных данных.
- Staging поднимается сразу после вехи M1 (решение 95). Разделы 13.1, 13.6, веха M9 в разделе 16.2.
- Показатели пилота записаны один раз, в разделе 16.7. Таблица раздела 1.1 снята (решение 96).
- Критические исправления Next.js и React ставятся за 24 часа, контейнеру `web` закрыты лишние исходящие соединения, ключ AI есть только у `worker` (решение 97). Разделы 13.3, 13.5, 14.2 (угроза T18), 21.

- GitHub Actions включается по решению владельца, когда проект готов (решение 99). Разделы 8.9, 9.2, 13.6, 16.4.
- Клавиши F8 и F9 в портале не используются, действия остальных клавиш названы явно (решение 100). UX-S-14.
- Уточнения по итогам вехи M0:

  - 8.11: имена слоя 2 токенов, пять поправок контраста, метки тёмной темы, группа "Настройки" на схеме панели;

  - 9.4: кеш компонентов из генератора Next.js выключен;
  - 10.3: служебные колонки заполняет база, правила применения миграций;
  - 11.1: пул соединений и окружение создаются при первом обращении, сервис получает исходную ошибку базы;
  - 13.3: том базы монтируется в `/var/lib/postgresql`;
  - 13.5: строгая проверка адреса базы;
  - 14.4: режим отчётов с вехи M0, запрет встраивания действует сразу, заголовки на всех ответах.
- Новые открытые вопросы: 43 (что приходит в `company_id`), 44 (коды модулей между приложениями), 45 (файл позы Теза "Планирование").
