# 0001. Версии стека и закрепление зависимостей

Дата: 20.11.2026. Веха: M0. Статус: принято. Node.js 26 вместо 24 владелец продукта подтвердил отдельно 20.11.2026.

## Контекст

Раздел 9.2 ТЗ называет версии, актуальные на день написания. Владелец продукта 20.11.2026 разрешил брать более новые стабильные версии с исправлениями, если это не нарушает согласованность стека.

## Решения

| Что | В ТЗ | Взято | Почему |
|---|---|---|---|
| Node.js | 24 LTS | 26.13.1 (ветка 26, LTS "Lithium") | С 28.10.2026 ветка 26 в активной поддержке, поддержка до 30.04.2029. Ветка 24 с 20.10.2026 только в сопровождении, до 30.04.2028. Все пакеты стека заявляют поддержку 26 |
| Next.js | 16.4.x, не ниже 16.4.5 | 16.4.6 | Последний выпуск ветки, старше 7 дней |
| React | 19 | 19.3.1 | Последний выпуск с исправлениями. Генератор ставит 19.3.0 |
| TypeScript | strict | 5.9.3 | Вышла 7.0, но генератор Next.js 16.4.6, плагин Next.js и typescript-eslint работают с веткой 5. Переход: когда на 7 перейдёт генератор Next.js |
| ESLint | не названа | 9.39.5 | Вышла 10, но `eslint-config-next` 16.4.6 рассчитан на 9 |
| Tailwind CSS | 4 | 4.3.5 | Последний выпуск с исправлениями |
| pnpm | не названа | 12.21.0 | Последний выпуск. Даёт проверки цепочки поставок, см. ниже |
| Vitest | не названа | 5.1.0 | Выпуск 5.1.1 моложе 7 дней на день установки |

Все прямые зависимости записаны в `package.json` точной версией, без диапазонов. Это проверяет тест `tests/unit/project-config.test.ts`. Обновление версии: правка `package.json`, `pnpm install`, `node scripts/versions.mjs`.

## Защита цепочки поставок

Настройки в `pnpm-workspace.yaml`:

- `minimumReleaseAge: 10080`. Пакет ставится не раньше чем через 7 дней после публикации. Большинство подменённых выпусков снимают с реестра быстрее.
- `trustPolicy: no-downgrade`. Установка падает, если у версии пакета подтверждений происхождения меньше, чем у более ранней.
- `strictDepBuilds: true` и `allowBuilds`. Сценарии сборки зависимостей выполняются только у пакетов из списка. Сейчас список никому не разрешает сборку.
- `blockExoticSubdeps: true`. Зависимости зависимостей берутся только из реестра.

Срочное исправление безопасности моложе 7 дней ставится через `minimumReleaseAgeExclude` с записью в этом каталоге.

## Исключения

| Пакет | Настройка | Причина |
|---|---|---|
| `eslint-import-resolver-typescript@3.10.1` | `trustPolicyExclude` | Зависимость `eslint-config-next`. Выпуск ветки 3 от 21.04.2025 опубликован без подтверждения происхождения, а более ранние по дате выпуски ветки 4 с подтверждением. Издатель тот же, что у остальных выпусков, репозиторий `import-js/eslint-import-resolver-typescript`. Пакет работает только при запуске линтера и в образ приложения не попадает |

| `chromium-bidi@157.0.8090-0` | `trustPolicyExclude` | Зависимость `puppeteer-core`, через него `lighthouse` и `@lhci/cli` (команда `pnpm lighthouse`). Пакет перешёл на ежедневные выпуски с учётной записи команды Chrome DevTools без подтверждения происхождения, более ранние выпуски его имели. Версию точно закрепляет сам `puppeteer-core` 25.17.0, на день установки ей 44 дня. Пакет работает только при замере Lighthouse и в образ приложения не попадает |

## Замены версий

| Пакет | Замена | Причина |
|---|---|---|
| `basic-ftp` | 6.2.6 вместо 5.3.1 (`overrides`) | Уязвимость высокой степени в версиях до 6.2.0 (отказ в обслуживании при разборе списка файлов FTP). Пакет приходит через `@lhci/cli` и нужен только для файлов настройки прокси по FTP, которыми проект не пользуется. Замена убирает замечание из `pnpm audit` |

## Что это стоит

- Версия Node.js расходится с таблицей раздела 9.2 ТЗ. Правка внесена в предложения к версии 1.1 ТЗ.
- Правило 7 дней задерживает обычные обновления на неделю.
