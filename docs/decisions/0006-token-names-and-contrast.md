# 0006. Токены оформления: имена слоёв и поправки контраста

Дата: 20.11.2026. Веха: M0. Статус: принято.

## Три слоя

Файл `src/ui/tokens.css` (ТЗ, раздел 8.11, требование UX-S-12).

| Слой | Что в нём | Кто меняет |
|---|---|---|
| 1 | Значения Smartup Web под именами `--sm-*`. Источник: `docs/design/smartup-tokens.scss` | Меняется при новой поставке Smartup Web |
| 2 | Смысловые цвета: `background`, `primary`, `destructive` и другие. Ссылаются на слой 1 | Меняется редко |
| 3 | Размеры, скругления, шрифт, точки перелома | Меняется редко |

Файлы экранов используют только классы слоёв 2 и 3. Имена `--sm-*`, значения цветов и размеры вида `h-[52px]` вне файла токенов запрещены, это проверяет `pnpm check`. Совпадение слоя 1 с поставкой проверяет тест `tests/unit/tokens.test.ts`.

## Имена слоя 2

Набросок раздела 8.11 ТЗ называет слой 2 так: `--color-brand`, `--color-bg`, `--color-surface`, `--color-text`. В портале взяты имена, которых ждут компоненты shadcn/ui. Смысл тот же.

| В наброске ТЗ | В портале | Класс |
|---|---|---|
| `--color-bg` | `--color-background` | `bg-background` |
| `--color-surface` | `--color-card` | `bg-card` |
| `--color-text` | `--color-foreground` | `text-foreground` |
| `--color-text-muted` | `--color-muted-foreground` | `text-muted-foreground` |
| `--color-brand` | `--color-primary` | `bg-primary` |
| `--color-link` | `--color-link` | `text-link` |
| `--color-border` | `--color-border` | `border-border` |
| `--color-field-border` | `--color-input` | `border-input` |
| `--color-danger` | `--color-destructive` | `text-destructive` |
| `--color-success` | `--color-success` | `text-success` |
| `--color-warning` | `--color-warning` | `text-warning` |

## Поправки контраста

Требование: текст к фону не ниже 4,5:1 (WCAG 2.2, уровень AA). Пять значений поставки его не проходят. В слое 1 они оставлены как в поставке, слой 2 ссылается на исправленное значение (переменные `--hub-*`).

| Токен слоя 2 | В Smartup Web | В портале | Контраст был | Контраст стал |
|---|---|---|---|---|
| `label-green-fg` | `#1A8F57` | `#157A4A` | 3,71 | 4,85 |
| `label-orange-fg` | `#B26A00` | `#9A5B00` | 3,86 | 4,94 |
| `label-teal-fg` | `#0E8577` | `#0B7468` | 4,06 | 5,08 |
| `destructive-on-bg` | `#C9302C` | `#B92925` | 4,37 | 5,05 |
| `muted-foreground` | `#6A7375` | `#667072` | 4,47 | 4,69 |

Оттенок сохранён, изменена только светлота.

### Тёмная тема

В поставке метки статуса в тёмной теме сохраняют цвет текста светлой темы на прозрачном фоне: контраст на карточке от 2,68 до 4,32. В портале текст меток в тёмной теме светлый, фон прозрачный, рамка цветом текста.

| Метка | Текст в тёмной теме | Контраст на карточке |
|---|---|---|
| серая | `#B4BCBF` | 9,20 |
| зелёная | `#5DD49D` | 9,61 |
| оранжевая | `#F5C16C` | 10,75 |
| фиолетовая | `#C7A0EA` | 8,15 |
| синяя | `#79CBE9` | 9,74 |
| бирюзовая | `#6FD6C9` | 10,25 |

## Как это проверяется

`scripts/checks/contrast-pairs.json` перечисляет 25 пар "текст, фон". `scripts/checks/contrast.mjs` считает контраст каждой пары в обеих темах по значениям из `tokens.css`. Полупрозрачный фон перед расчётом накладывается на цвет карточки. Проверка входит в `pnpm check`. Новая пара цветов в интерфейсе добавляется в этот список.

## Размеры

| Что | Значение | Класс |
|---|---|---|
| Шапка | 52 px | `h-header` |
| Строка списка | 48 px | `h-row` |
| Кнопка, пункт меню | 40 px, в кабинете клиента 44 px | `h-control` |
| Поле ввода | 46 px | `h-field` |
| Скругление карточки | 14 px | `rounded-card` |
| Скругление кнопки и поля | 10 px | `rounded-control` |
| Основной текст | 14 px, в кабинете клиента 16 px | `text-base` |

Атрибут `data-zone="client"` на корне кабинета клиента переключает размеры: сначала телефон, цель нажатия не меньше 44 px.

Точки перелома взяты из `docs/design/smartup-breakpoints.scss`: 600, 1024, 1200, 1280, 1440. Стандартные точки Tailwind отключены, чтобы словарь был один.
