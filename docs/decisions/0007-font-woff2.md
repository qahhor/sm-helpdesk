# 0007. Шрифт: свои файлы WOFF2 из шрифта пакета бренда

Дата: 20.11.2026. Веха: M0. Статус: принято.

## Контекст

Пакет бренда содержит Montserrat в четырёх начертаниях (400, 500, 600, 700), формат TTF, вместе 1,3 МБ. В поставке Smartup Web шрифт подключён с Google Fonts.

## Решение

1. Шрифт отдаёт сам портал. Внешних серверов шрифтов нет: это лишняя зависимость, лишний запрос к третьей стороне с адресом клиента и послабление политики CSP.
2. Файлы для веба собирает `scripts/fonts/build.mjs` (`pnpm fonts:build`) из TTF пакета бренда. В WOFF2 остаются латиница с расширениями, кириллица с расширениями, пунктуация, цифры, знаки валют. Четыре файла вместе весят 235 КБ вместо 1,3 МБ.
3. Собранные файлы лежат в `src/ui/fonts/` и коммитятся. Рядом записаны контрольные суммы исходников. Если шрифт в пакете бренда обновили, а файлы для веба не пересобрали, `pnpm check` и тест `tests/unit/font-coverage.test.ts` падают.
4. Тест проверяет, что в каждом файле есть узбекские знаки (`ʻ`, `ʼ`, `ў`, `қ`, `ғ`, `ҳ`), казахские и турецкие буквы (UX-S-16), русский и английский алфавит, цифры.
5. `font-display: swap`: текст виден сразу системным шрифтом и перерисовывается, когда Montserrat загружен.

## Что это стоит

Знак вне набора (например, китайский иероглиф в тексте обращения) показывается системным шрифтом. Набор расширяется правкой списка диапазонов в `scripts/fonts/build.mjs`.
