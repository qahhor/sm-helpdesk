# 0008. Витрина компонентов и компоненты shadcn/ui

Дата: 20.11.2026. Веха: M0. Статус: принято.

## Витрина

Страница `/<язык>/dev/ui` показывает все базовые компоненты в зоне рабочего места и в зоне клиента, в светлой и тёмной теме, на трёх языках. На ней проверяется длина узбекских подписей (узбекский текст длиннее русского на 20-30%) и набор знаков шрифта.

Витрина открыта только при `HUB_SHOWCASE=1`. С вехи M1 рабочее место закрыто входом, поэтому витрина вынесена из него на отдельный адрес (до M1 она была на `/<язык>/agent/dev/ui`). Оболочка у неё та же, но без меню пользователя: снимки не изменились. При другом значении страница отвечает 404. В production флаг включается только на `localhost`: это проверяет схема окружения (`src/env.ts`).

Эталонные снимки витрины лежат в `tests/e2e/__screenshots__`. Тест сравнивает с ними страницу при каждом прогоне: случайное изменение токена или компонента видно сразу. После намеренного изменения снимки обновляются командой `pnpm test:e2e --update-snapshots` и просматриваются глазами.

## Компоненты

Компоненты взяты по образцу shadcn/ui и лежат в `src/ui/components`: это код в репозитории, а не зависимость. Отличия от исходных файлов shadcn/ui:

- размеры и цвета только из токенов (`h-control`, `rounded-control`, `bg-primary`), без чисел в классах;
- направления только логические (`ps-`, `pe-`, `start-`, `end-`) под будущие языки с письмом справа налево (FR-I18N-09);
- встроенных стилей в разметке нет: этого требует политика CSP.

Основа доступности (фокус, клавиатура, роли) остаётся от Radix.

`components.json` описывает пути проекта для команды `shadcn add`. Добавленный командой компонент нужно привести к правилам выше: `pnpm check` покажет нарушения.

## Бренд

- В `public/brand` лежат только используемые файлы: четыре файла Теза и два файла логотипа. Тест сверяет их с пакетом бренда байт в байт.
- `TezMark` и `Logo` сами выбирают файл для светлой или тёмной темы. Для постоянного тёмного фона (шапка) задаётся `onDark`.
- У `TezMark` нет параметров поворота, отражения и цвета. Размеры из закрытого списка: 24, 32, 40, 64, 96, 120 px. До 40 px берётся значок, выше основной Тез. Охранное поле 1/6 размера задано классом.
- Крупный Тез на экране один (UX-B-04).
- Кнопка "опасное действие" сделана контурной на светло-красной подложке: белый текст на красном в тёмной теме не проходит контраст.
