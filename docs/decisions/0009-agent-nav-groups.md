# 0009. Рабочее место: группы верхней панели и горячие клавиши

Дата: 20.11.2026. Веха: M0. Статус: принято.

## Группы

В разделе 8.11 ТЗ пятая группа названа по-разному: на схеме "Ещё", в таблице групп по этапам "Настройки". Взята таблица: Работа, Знания, Клиенты, Аналитика, Настройки.

Группы видны с первой вехи, чтобы порядок в панели не менялся от версии к версии. Пункт внутри группы появляется, когда его веха включена: код вехи добавляется в `ENABLED_MILESTONES` (`src/ui/shell/agent/nav-config.ts`). Пока в группе нет пунктов, её меню говорит "Разделы появятся позже".

| Группа | Пункты этапа 1 и вехи |
|---|---|
| Работа | Очереди (M3) |
| Знания | Решения (M5), Кандидаты (M5c), Известные проблемы (M5c), Знания из кода (M8c) |
| Клиенты | Организации (M1), Идеи (M7), Объявления (M5c) |
| Аналитика | Показатели (M8), Сводки (M8b), Разбор ответов AI (M5b) |
| Настройки | Все настройки (M1, только `admin`) |

Пункт может быть ограничен ролями (`roles` в `nav-config.ts`). Первый такой пункт: "Все настройки" с вехи M1 виден только роли `admin` (решение 0019). Группа "Настройки" остаётся видна всем, у остальных сотрудников в ней надпись "Разделы появятся позже".

## Ширина окна

- Шире 1200 px: пять групп в панели.
- 1200 px и уже: группы свёрнуты в кнопку "Разделы". Граница взята из Smartup Web (`max-width: 1200px`), поэтому в токенах есть отдельный вариант `nav-full` (`width > 1200px`): обычная точка перелома Tailwind включилась бы на один пиксель раньше.
- Ниже 1024 px корневой элемент получает `data-layout="compact"`. Экраны со сложной раскладкой читают этот признак.

Панель тёмная в обеих темах, высота 52 px, логотип для тёмного фона.

## Горячие клавиши

Список в `src/ui/hotkeys/registry.ts` (UX-S-14). Действия взяты из окна "Горячие клавиши" Smartup Web (снимок 3.13 поставки).

| Клавиши | Действие |
|---|---|
| F2, Ctrl+K | Открыть палитру команд с поиском |
| F3 | Поиск в таблице |
| F4 | Открыть фильтр |
| F7 | Обновить таблицу |
| Alt+A | Добавить |
| Alt+E | Изменить |
| Alt+S | Сохранить |
| Alt+Q | Закрыть текущую страницу |
| Ctrl+Enter | Завершить |
| F8, F9 | В портале не используются |

Строки F8 и F9 на снимке поставки не видны. Владелец продукта решил 20.11.2026: в портале эти клавиши не используются, своих действий на них нет, действия Smartup Web не повторяются (решение 100 ТЗ). В реестре клавиш их нет, тест это проверяет.

## Доступ

В вехе M0 рабочее место открыто без входа и не показывает данных. Проверка входа и роли сотрудника добавляется в раскладку `(agent)` в вехе M1.
