## Гости

Членство с `source = 'guest'` входа не даёт: его не учитывают выбор организации (`resolveClient`, `listMyOrganizations`), переключение организации, ссылка для входа на email и ссылка из бота. Сами гости появятся в M4 с приёмом почты (человек написал в поддержку с адреса, которого нет среди участников). Правило закреплено сейчас, чтобы в M4 не пришлось менять вход.

## Политика обработки данных

- Тексты лежат файлами в `content/legal/`: `manifest.json` с датой редакции и `privacy.<язык>.md`. Формат простой: `# ` заголовок, `## ` подзаголовок, `- ` пункт, остальное абзацы. Разметка HTML и ссылки не разбираются, текст выводится как текст: опечатка или вставка в файле не станет кодом на странице.
- Пока `manifest.json` нет, политика выключена: страница отвечает 404, строк о ней нет. Нет перевода на язык посетителя: показывается русский текст с пометкой.
- Страница `/{язык}/legal/privacy` открыта без входа, сессию не читает и в базу не ходит. Это держит правило линтера для группы маршрутов `(public)`: там нельзя импортировать `next/headers` и модуль `hdu`.
- Шаг первого входа показывает строку со ссылкой на политику и записывает в учётную запись версию, которую видел пользователь. Вышла новая редакция: кабинет один раз показывает короткий шаг "Обновлена политика обработки данных". Ссылка на политику стоит внизу страниц входа.
- Черновик для юриста: `docs/legal/privacy-draft.ru.md`, собран из раздела 14.6 ТЗ. В портале не показывается.
