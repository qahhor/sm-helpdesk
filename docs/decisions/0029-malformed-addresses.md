# 0029. Испорченные адреса страниц

Дата: 21.11.2026. Основание: итоговая проверка M2, отложенное замечание 8. Статус: принято исполнителем по поручению владельца закрыть отложенные замечания.

1. Next.js 16 разбирает адрес до страницы, и на испорченной последовательности `%XX` (например, `/ru/tickets/%E0%A4%A`) отвечает ошибкой 500 без текста. Внутренняя перезапись в прокси не помогает: исходный адрес всё равно разбирается.
2. Прокси страниц (`src/proxy.ts`) проверяет адрес и перенаправляет такой запрос на `/<язык>/not-found`: человек видит обычную страницу "не найдено" своего языка с кодом 404. Адрес без языка сначала получает язык, как раньше.
3. Обработчики `/api/` прокси не проходят (так задано его правилом адресов), на испорченный адрес они по-прежнему отвечают 500. Их вызывают страницы портала и программы, а не человек вручную; менять правило адресов прокси ради этого не стоит.
