# 0045. Отбор обращений в пробном прогоне правила

Дата: 24.11.2026. План: `docs/plans/W5.md`, задача 2. Статус: принято исполнителем, в ТЗ этих подробностей нет (FR-AUTO-08 говорит только "на последних 100 обращениях").

1. **Событие правила по истории обращения.** Очередь событий предметной области (`hdc_domain_events`) хранится 30 суток, поэтому прогон смотрит историю обращения. Создание было у каждого обращения. "Клиент ответил" и "сотрудник ответил": публичные сообщения клиента или сотрудника (`hdt_ticket_messages`, без внутренних заметок и автоматических ответов правил). Смена статуса и приоритета, оценка, нарушение срока: события истории `status`, `priority`, `rated`, `due`; изменение, сделанное правилом (отметка `byRule`), не в счёт, как и у настоящего применения. Окно прежнее: последние 100 обращений по номеру, из них берутся те, у которых событие было.
2. **"Срок скоро" восстанавливается по срокам.** Следа в истории это событие не оставляет: колонка момента очищается при записи события. Обращение считается пережившим его, если момент "скоро" (`soonMoment`) по нынешнему сроку уже наступил, а срок в этот момент ещё ждали (первого ответа или решения не было). Цена ошибки: если срок сдвигали или процесс стоял в момент "скоро", прогон может ошибиться на такие обращения.
3. **Изменения из макроса.** Действия макроса пишут обычные события истории без отметки, а событие предметной области с отметкой "порождено правилом". Прогон такие изменения считает событием, настоящее применение нет. Цена ошибки: число совпадений для правил на смену статуса и приоритета может быть завышено на обращения, которые меняли только макросом.
4. **"Нет активности".** Отбор и определение молчания общие с настоящим просмотром (`silentSelection`, `silentTicketsTx`): молчание не меньше заданных часов, те же статусы просмотра и та же проверка статуса на снимке. Берутся последние 100 молчащих обращений по номеру. Момент включения правила и уже записанные срабатывания не учитываются: прогон отвечает, каким обращениям правило подошло бы сейчас.
5. **Страница называет признак отбора** ("обращения с событием ... среди последних 100", "молчат N ч и дольше") и число отобранных; поле `checked` теперь значит "сколько обращений отобрано и проверено условиями".
