# 0059. Виджет: загрузчик, страницы "Сообщить", "Мои обращения" и страница для приложения

Дата: 25.11.2026. Веха: M6, задачи 4-7. План: `docs/plans/M6.md` (решения 1-17 подтверждены владельцем 25.11.2026). Статус: принято исполнителем. Здесь только то, чего нет ни в ТЗ, ни в решениях плана.

## Загрузчик (задача 4)

- Интерфейс: `SmartupHub.init({ hubUrl, embedKey, locale, theme, button, getContextToken, getHints, onTicketCreated })`, `open({ mode: 'report' | 'tickets' })`, `reportError({ code, message })`. `theme` строка или функция (UX-S-09), `button: false` убирает плавающую кнопку, если у Smartup Web есть пункт "Помощь". `onTicketCreated` получает только номер.
- Неверный `hubUrl` (не https, кроме `localhost` и `127.0.0.1`) или `embedKey` (не 32 шестнадцатеричных знака): виджет не включается, в консоль одна строка.
- Адрес `iframe`: `{портал}/{язык}/embed/{report|tickets}?key=<embed_key>&origin=<адрес хозяина>`. Параметр `origin` нужен браузерам без `location.ancestorOrigins` (Firefox). Если браузер назвал родителя сам, параметр его не подменяет: при расхождении страница не отвечает никому. У `iframe` `referrerPolicy = no-referrer`: путь страницы Smartup Web не попадает в журнал портала.
- Стили: закрытый Shadow DOM и `adoptedStyleSheets`. Элемент `style` создаётся только в браузере без таблиц стилей CSSOM. Атрибут `style` не ставится нигде, поэтому политике CSP Smartup Web не нужен `unsafe-inline`. Нужны только `script-src` и `frame-src` с адресом портала (раздел 17).
- Цвета, шрифт, скругления и высота кнопки подставляются сборкой из `src/ui/tokens.css`, ширина панели 400 px из ТЗ, панель на весь экран уже `--breakpoint-tablet`.
- Сборка без сжатия имён: результат около 4,5 КБ в сжатом виде при пределе 15 КБ. Комментарии исходника в файл не попадают.
- Режим B по ошибке `getContextToken` включается только при первом токене (`ready`). Ошибка продления (`need-token`) режим B не открывает: страница виджета показывает своё состояние, иначе посреди заполнения формы открылась бы новая вкладка.
- Формат адреса режима B: `{портал}/{язык}/tickets/new#widget=1&hints=<JSON подсказок>`. Страницу, которая его разбирает, строит задача 8.
- Уведомление `reportError` скрывается само через 20 секунд или по "Скрыть". Текст ошибки в нём не длиннее 200 знаков и только текстом.

## Проверка протокола

- Пакета jsdom в проекте нет, а новые пакеты без согласования не ставятся. Модульные тесты протокола идут в Node: собранный файл загрузчика выполняется в `node:vm` с простыми окном, документом и элементами (`tests/unit/widget-loader.test.ts`), сторона страницы проверяется чистыми функциями `src/ui/widget/protocol.ts` (`tests/unit/widget-protocol.test.ts`). Настоящий браузер: браузерные тесты задачи 5.
- Сторона страницы проверяет сообщения схемой `zod/mini`: полная библиотека Zod в браузере заняла бы заметную часть бюджета 170 КБ.
