# 0069. Команда начальных данных, инструкции и памятки запуска

Дата: 26.11.2026. План: `docs/plans/M9-prep.md`, задачи 6-9, решения 9-12 (подтверждены владельцем). Статус: принято исполнителем. Здесь только то, чего нет в плане.

## Начальные данные (задача 6)

1. **Транзакция на запись, а не на раздел.** План назвал одну транзакцию на раздел файла. Команда вызывает функции экранов настроек модулей (`saveTemplate`, `savePlaybook`, `saveHolidays` и другие), а у каждой своя транзакция с записью аудита; общей транзакции на раздел у слоя api нет. Вместо неё весь файл проверяется до первой записи: строгая схема (`src/cli/seed-pilot-schema.ts`), повторы ключей, ссылки на модули. Ошибка в файле ничего не меняет и называет раздел, номер записи и её ключ. Цена: сбой базы посреди запуска оставляет уже записанное; повторный запуск дописывает остальное, записанное не дублирует.
2. **Пишется только отличающееся.** Команда читает справочники функциями модулей и вызывает запись только для записей, которые отличаются от базы: второй запуск даёт ноль изменений и ноль записей аудита. Значение по умолчанию из кода, равное файлу (например, `per_user` голосов), не записывается.
3. **Ключи:** модуль по коду, год праздников, приоритет срока, шаблон по коду, памятка по паре "модуль и тип", тег по названию без учёта регистра, сотрудник по адресу, черновик решения по языку оригинала и названию. Созданный черновик дальше ведёт редактор: файл его не перезаписывает. Сотрудник, который уже есть или ждёт ответа на приглашение, не приглашается снова (иначе прежняя ссылка отзывается).
4. **Модули загружаются целиком, как `hub modules:import`:** модуль справочника, которого нет в файле, скрывается. Раздел `modules` в файле необязателен.
5. **Разделы сверх плана:** сроки SLA и рабочий календарь (необязательные, иначе значения из кода), проверка предустановленных правил (только отчёт, правила не меняются). Настроек уведомлений в файле нет: план их не называет, значения из кода действуют.
6. **Приглашения уходят письмом** (`inviteStaffByMail`, как на экране "Сотрудники"), от имени администратора `--admin`. Почта выключена: команда предупреждает, ссылку выдаёт `hub staff:create`.
7. **Вход администратора из консоли считается свежим** (`adminContextByEmail`): человек у консоли сервера вошёл в неё сам. Новая функция `createTag` (тег с цветом от администратора) добавлена в слой api справочников: прежде тег создавался только на лету при постановке на обращение.
