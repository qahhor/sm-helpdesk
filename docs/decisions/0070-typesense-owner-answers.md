# 0070. Typesense: ответы владельца

Дата: 26.11.2026. План: `docs/plans/W6-typesense.md`.

Владелец согласовал новый внешний сервис Typesense (правило CLAUDE.md о внешних сервисах) и ответил на вопросы плана:

- сервер production 16 ГБ; до него Typesense на production не включается, поиск идёт через PostgreSQL;
- версия 30.2 на разработке и пилоте, перед production последняя стабильная с прогоном контрактных тестов;
- поиск сотрудника по внутренним заметкам и переписке разрешён, отдельной коллекцией с ключом только сотрудника;
- синонимы, словарь узбекского и курирование ведёт администратор поддержки;
- тексты пустых запросов подсказки хранятся 90 дней, затем удаляются.
