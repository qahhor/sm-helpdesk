# 0084. Модели по целям, цена по модели, пределы и расходы AI

Дата: 26.11.2026. План M5b, задача 1, решения 1, 2, 3, 11, 12. Принято исполнителем по общему поручению владельца, список решений вехи будет в отчёте M5b. Статус: принято исполнителем.

## Что решено

1. **Модель по цели** (`modelForPurpose` в `src/modules/hda/pref.ts`): настройка `ai.models` (только из закрытого списка `AI_MODELS`), затем переменная окружения уровня (`AI_MODEL_FAST`, `AI_MODEL_QUALITY`, теперь необязательные), затем значение по умолчанию: `first_line` на `claude-sonnet-5-5`, все остальные цели на `claude-haiku-5-5`. Клиент модели получает идентификатор модели в запросе, а не уровень.
2. **Цена по модели из ответа API** (`costUsd`): Opus 5.5 4 и 20, Sonnet 5.5 2 и 10, Haiku 5.5 0,10 и 0,50 долларов за миллион токенов. Модель с датой версии считается по своей модели, неизвестная по самой дорогой цене с событием `ai.unknown_model_price`. Заглушка считается по цене выбранной модели, чтобы учёт расходов проверялся без ключа.
3. **Договор с API** (`client/anthropic.ts`, не проверен на настоящем API): `structured` даёт `output_config.format` со схемой JSON из схемы Zod без ограничений длины и чисел; `effort` в `output_config`; поля `thinking` нет; `stop_reason: 'refusal'` даёт `AiResponseError('refusal')`; для Sonnet и Opus `fallbacks: 'default'` с заголовком `anthropic-beta: server-side-fallback-2026-07-01`.
4. **Пределы** (`callAi` в `src/modules/hda/api/run.ts`): месячный предел расходов (`ai.monthly_budget_usd`, 100) на все цели вместе и строка "отключено для всех" останавливают любой вызов; у `first_line` и `triage` ещё отключение организации и суточные пределы 20 на пользователя и 150 на организацию; у остальных целей прежний суточный предел 300, первая линия его не расходует. Для предела на пользователя журнал получил колонку `user_id` (автор текста), её нет в перечне плана.
5. **Задача `ai.budget`** раз в 10 минут: от 80% месячного предела организации, израсходовавшие больше `ai.cutoff_share` (25%), получают строку `hda_org_cutoffs` до конца месяца; от 100% строка без организации отключает всех. Новая строка один раз уведомляет администраторов (вид `ai_budget`). Снять отключение может администратор со свежим входом на `/agent/settings/ai`.
6. **Повтор** (`detectRepeat`): HMAC данных запроса с ключом из `ENCRYPTION_KEY`, без учёта регистра и пробелов; тот же хеш и цель в организации за 24 часа с решённым действием дают строку `repeated` без модели, вызывающий повторяет прошлый выбор.
7. **Помощник по умолчанию выключен** (`ai.enabled = false`): включает администратор. Порог `ai.min_score` по умолчанию 0 (решает уверенность подсказки) до подбора на наборе задачи 11.

## Цена

Если в ответе API окажется другое поле модели или другой вид отказа, учёт и разбор отказа поменяются в одном файле `client/anthropic.ts`. Порог 0 до задачи 11 означает, что помощник отвечает любым уверенным решением подсказки.
