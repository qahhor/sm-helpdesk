# 0087. Задача первой линии и сторожевая задача

Дата: 26.11.2026. План M5b, задача 4, решения 5, 7, 8, 12, 21, 22. Принято исполнителем по общему поручению владельца. Статус: принято исполнителем.

## Что решено

1. **Порядок** (`src/modules/hda/first-line/run.ts`): помощник не активен: молчит; три ответа: `reply_limit`; помощник или AI-обработка организации выключены: `ai_disabled`. Затем передача кодом **до вызова модели**: нет текста (`no_text`), язык (`language`), просьба о человеке (`customer_request`), обязательная тема (`restricted_topic`). Такие обращения модель не видит вовсе: дешевле и вход меньше. Затем известная проблема (`matchKnownProblem`, M5c, пока "нет"), поиск `searchSolutions` от имени автора (актор клиента из действующего членства, аудитория `clients`), порог `ai.min_score` (точное совпадение сигнатуры проходит всегда), P1 без точного совпадения: передача сразу без модели. Один вызов `first_line` со схемой 11.12, `effort: low`, сроком 25 секунд и поиском повтора.
2. **Правила кода сильнее модели.** Флаги модели `customerAsksHuman` и `restrictedTopic` только добавляют передачу. Решение обязано быть среди найденных; машинный перевод с другими инвариантами (FR-AI-12) даёт `low_confidence`. Вопрос только с двумя разными найденными решениями и при `ai_reply_count < 2`. Вопросы перед передачей отбираются по типу обращения, не больше трёх. При P1 с точным совпадением ответ точным решением и сразу передача `p1`. Иначе передача `low_confidence` (решения были) или `no_solution`.
3. **Сбои.** Нет ключа и любая ошибка вызова (сеть, срок, не JSON, обрезка, отказ, схема): `ai_failure` с подтверждением без Теза; предел: `ai_limit`. Повтор (`repeated`): прошлое решение, если оно снова среди найденных, иначе `low_confidence`.
4. **Одно задание за раз.** Очередь `ai.first_line` с политикой `stately` и ключом обращения; запись ответа сверяет `ai_reply_count`, прочитанный заданием до вызова: второе задание, ответившее позже, ничего не пишет.
5. **Сторож** `ai.watchdog`: через 60 секунд после создания и после ответа клиента (с обращением) и раз в минуту по всем: помощник активен, нет сообщения помощника дольше 60 секунд после создания или клиент ответил дольше 60 секунд назад, а помощник молчит: передача `ai_failure`.
6. **Заглушка** получила режимы "враждебная" (`StubAiClient.hostile()`) и "сломанная" (`broken`: `not_json`, `truncated`, `refusal`, `slow` с учётом срока запроса).
7. **Разбор не записывается в этой задаче.** Таблица `hda_triage_suggestions` создаётся задачей 7; ответ модели уже содержит разбор и проверяется схемой, запись и задание `ai.triage` (решение 6) переходят в задачу 7.

## Цена

Обращение, переданное кодом до вызова модели, не получает разбора из того же вызова: после задачи 7 его делает отдельный вызов `triage`. Порог 0 до задачи 11.
