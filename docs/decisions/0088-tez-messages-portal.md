# 0088. Сообщения Теза и кнопки клиента в портале

Дата: 26.11.2026. План M5b, задача 5, решения 9, 10, 23. Принято исполнителем по общему поручению владельца. Статус: принято исполнителем.

## Что решено

1. **Показ из ссылок** (`src/app/[locale]/(portal)/tickets/[number]/AiMessage.tsx`): вид Теза рисуется только у сообщения с типом автора `ai` и `ai_payload`, вне текста сообщения. Ответ: вступление по идентификатору из `messages/*.json`, заголовок и шаги из `hdk_published` через `clientSolutionPage` (язык страницы, затем цепочка FR-SOL-10, пометки "нет на вашем языке" и "машинный перевод"), "Открыть решение полностью" на `/help/a/[ref]`. Решение снято с публикации или стало внутренним: "Решение больше не действует" и только "Нужен сотрудник". Решение опубликовано позже ответа: "Решение обновлено", показан текущий текст. Вопрос: текст собирается из заголовков двух решений, кнопки "Выбрать: <заголовок>". Передача: срок ответа сотрудника (начало рабочего времени, если сейчас нерабочее) и вопросы по идентификаторам. Подтверждение без Теза (`ack`): без знака и подписи.
2. **Кнопки** (`aiFeedback`, `src/modules/hdt/api/ai-feedback.ts`): одна функция для портала, письма и Telegram. Обращение читается под политикой клиента, сообщение обязано быть последним сообщением помощника, помощник активен и ждёт реакции ("Ждём вашего ответа"). "Помогло" (только у ответа решением): "Решено", `resolved_by_ai`, итог "Решено" с решением. Клиент по триггеру не может менять `ai_state`, поэтому изменение делает система после проверки права клиента. "Не помогло": передача `not_helped`, "Нужен сотрудник": `customer_request`. Выбор в вопросе: выбранное решение ответом без вызова модели (третий ответ при исчерпанном пределе даёт передачу `reply_limit`). Каждое нажатие: внутреннее событие истории `ai_feedback` и запись `ticket.ai_feedback` в журнал аудита.
3. **"Думает"** (`AiThinking.tsx`): пока помощник включён, сообщений помощника нет и с создания меньше 70 секунд; обновление раз в 3 секунды, анимация `motion-safe`.
4. **Подпись формы** нового обращения (FR-AI-19) показывается, только если помощник ответит первым этой организации (`assistantAnswersFirst`). Учёт рабочего времени в подписи (UX-C-04) не сделан: срок называет сообщение о передаче.
5. **Браузерный тест S8** идёт отдельным проектом `ai` после остальных: он включает помощника для всех новых обращений. Время в браузере не подменяется.
6. **Виджет** показывает сообщение помощника его служебным текстом: вид Теза в виджете не сделан.

## Цена

Тексты Теза - черновик исполнителя по таблице "Как говорит Тез"; их утверждает ответственный за тексты, замена идёт в `messages/*.json` без кода. В виджете клиент видит служебный текст вместо ответа решением, пока виджет не получит тот же показ.

Тесты: `tests/integration/hdt-ai-feedback.test.ts`, `tests/e2e/ai-first-line.spec.ts`.
