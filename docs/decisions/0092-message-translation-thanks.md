# 0092. Перевод сообщения клиента и благодарность с AI

Дата: 26.11.2026. План M5b, задача 9, решение 24; FR-AG-11, FR-TK-14, перечень 14.3. Принято исполнителем по общему поручению владельца. Статус: принято исполнителем.

## Что решено

1. **"Перевести"** у публичного сообщения клиента на странице сотрудника, если AI-обработка организации включена и сотрудник ведёт обращения. Нажатие ставит строку "готовится" в `hda_message_translations` от имени сотрудника (миграция 0095) и задание `ai.message_translation`; текст пишет фоновый процесс. Язык перевода: язык интерфейса сотрудника. В модель уходит только текст этого сообщения после очистки (имена, адреса, телефоны, невидимые знаки, цитата письма), до 3000 знаков. Перевод показан под оригиналом с пометкой "Машинный перевод" и строкой "не основание для действий с правами, данными и оплатой", в переписку не попадает, клиент таблицу не видит. Страница сама не обновляется: сотрудник обновляет её.
2. **Срок жизни 24 часа**: строки старше суток удаляет задание `ai.budget` (раз в 10 минут), показ тоже не берёт строки старше суток.
3. **Благодарность.** Решение простыми признаками M3 остаётся первым и мгновенным. Если код счёл ответ благодарностью и AI-обработка организации включена, задание `ai.thanks` спрашивает модель о тексте одного сообщения. Ответ "не благодарность" открывает обращение заново: "Решено" > "В работе", событие статуса от системы с причиной `ai_thanks` и идентификатором сообщения, запись журнала аудита, события для правил, пересчёт сроков. Подтверждение, сбой, предел и отсутствие ключа оставляют решение кода. Сомнение кода открывает обращение сразу, модель его не видит.
4. **Переписка только пополняется**: признак `is_thanks` сообщения не меняется (у роли портала нет права обновлять сообщения, и давать его не нужно); сообщение, по которому модель открыла обращение, убирается из списка "Не открыли обращение" по событию с его идентификатором.

## Цена

Включённый переключатель помощника для перевода и благодарности не нужен: достаточно AI-обработки организации. Перевод без автообновления страницы: сотрудник ждёт и обновляет сам.
