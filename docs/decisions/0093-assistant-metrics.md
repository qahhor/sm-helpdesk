# 0093. Показатели AI-помощника

Дата: 26.11.2026. План M5b, задача 10; FR-MET-06, FR-AI-18, FR-LINE-08, FR-SOL-19, правило линий 10.5. Принято исполнителем по общему поручению владельца. Статус: принято исполнителем.

## Что решено

1. **Блок "AI-помощник" на `/agent/metrics`** по обращениям, созданным в периоде, которые вёл помощник (`ai_state` не `none`): доля решённых без сотрудника (`resolved_by_ai`), передачи по причинам, время первого ответа помощника (среднее и медиана в секундах, настенное время: помощник отвечает круглосуточно), оценка клиентов по обращениям, решённым помощником, число открытых заново после "Помогло" (после события `ai_feedback` "helped" переход из "Решено" в работу). По журналу вызовов: доля ответов решением, отмеченных неверными, и расход на AI за текущий месяц по Ташкенту. В пустом периоде блока нет, как и остальных чисел.
2. **Линия AI-помощника** в показателях линий: обращение на линии помощника, пока `ai_state = 'active'`; включение (`ai_state`) и передача (`ai_handoff`) восстанавливаются по истории так же, как очередь и статус. Решено на линии помощника: решено, пока помощник вёл обращение ("Помогло"). Время на линии помощника: до передачи.
3. **"Ответов помощника" в списке решений** (FR-SOL-19): число вызовов первой линии с решением кода `answer` и этим решением.
4. **Индексы** (миграция 0096): `hda_runs_i9 (solution_id) where decision = 'answer'` и `hda_runs_i10 (created_on) where decision is not null`; обращения периода идут по `hdt_tickets_i25 (created_on)`.

## Цена

Время первого ответа считается в настенных секундах, а не рабочих минутах, как у сотрудников: числа сотрудников и помощника не сравниваются напрямую. Открытые заново считаются по событию истории, а не по полю.
