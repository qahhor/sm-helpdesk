# 0095. Приёмка вехи M5b

Дата: 26.11.2026. План M5b, задача 12; ТЗ 16.2 (строка M5b), 15.6. Принято исполнителем по общему поручению владельца. Статус: принято исполнителем.

## Что решено

1. Веха принимается на заглушке модели: сценарий S8 проходит в браузере, пороги 15.6, которые держит код, пройдены на синтетическом наборе и наборе атак (`pnpm eval:ai`), передача за 60 секунд при выключенном Claude проверена интеграционными тестами.
2. Замер "правильное решение не ниже 80%" и "ответ вместо передачи не выше 3%" и проверка настоящего API остаются открытыми пунктами до получения 100 размеченных обращений и ключа Anthropic. До них помощник в production не включается: `ai.enabled` по умолчанию выключен.
3. Независимая проверка ветки свежим проверяющим не проведена в этой сессии и нужна перед слиянием.

## Цена

Решение о включении помощника для пилота принимается без замера качества на настоящих обращениях, если владелец решит включить его до получения набора.
