# 0098. Ведение известной проблемы

Дата: 27.11.2026. План M5c, задача 2; FR-KP-01..03, 10, FR-ADM-12, раздел 8.12. Принято исполнителем по общему поручению владельца. Статус: принято исполнителем.

## Что решено

1. **Точки входа** `src/modules/hdp/api/problems.ts`: создание, создание из обращения, правка (внутреннее название, модуль, обходной путь по номеру решения), статус, признак показа, сигнатуры, публичный текст, запрос машинного перевода, список, карточка. Пишут `agent_l2`, `care`, `admin`, читают все сотрудники; каждое изменение пишет журнал аудита той же транзакцией (`problem.*`, `ticket.problem_linked`).
2. **Создание из обращения** (решение 4 плана): внутреннее название из темы, модуль, сигнатура обращения (если она не занята другой активной проблемой), владелец создатель; обращение привязывается общей функцией привязки с событием истории `known_problem` (миграция `0100_hdt_known_problem_event.sql`). Публичных полей нет, признак показа выключен. Обращение, уже привязанное к проблеме, отказ `already_linked`.
3. **Признак показа** (решение 5): только при публичном названии и описании хотя бы на одном языке, видимых клиенту (текст сотрудника или принятый перевод), и без находок проверки на момент включения: обращение новой организации могло прибавиться после сохранения текста. Если правка убирает последний видимый текст показанной проблемы, признак снимается той же транзакцией с записью журнала.
4. **Проверка текста** (решение 6): `checkPublicText` в `hdp/util.ts` поверх `findInText` решений, ссылки вне `kb.allowed_domains` и названия и ИНН организаций привязанных обращений (целым словом, без учёта регистра, от четырёх знаков). Находка: отказ `text_findings` с видами находок; страница показывает только виды, текст в адрес не попадает.
5. **Машинный перевод** (решение 17): задача `problems.translate`, цель `problem_translation` (уровень `fast`), вход `<public_text>` с текстом сотрудника на языке оригинала. Перевод, потерявший ссылки или числа (`comparePlainInvariants`), не сохраняется. Текст сотрудника на языке задача не трогает. Принять перевод можно только без правки; правка делает его текстом сотрудника. Язык оригинала: первый язык, на котором сотрудник сохранил текст.
6. **Закрытие карточкой** недоступно: статус `closed` ставит только окно закрытия с итоговым текстом (задача 5).
7. **Черновик для AI-сотрудника** `createProblemDraft` (система): сигнатура и привязка обращений, без признака показа и текста; сигнатура, занятая активной проблемой, отказ `signature_taken`.
8. **Блок "Известная проблема"** в правой колонке обращения сотрудника; кнопка "Создать известную проблему" у `agent_l2`, `care`, `admin`.
