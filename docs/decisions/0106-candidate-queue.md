# 0106. Очередь кандидатов и решение из кандидата

Дата: 27.11.2026. План M5c, задача 10; FR-CAND-04, 06, 09, FR-SOL-04, 05, угроза T33. Принято исполнителем по общему поручению владельца. Статус: принято исполнителем.

## Что решено

1. **Очередь** `/agent/candidates`: по умолчанию новые, сортировка "больше источников, больше организаций, новее", фильтр статуса и модуля, поиск по заголовку и тексту общим помощником `containsText`. Видят и решают роли с правом черновика решения (agent_l1, agent_l2, care, admin); product нет.
2. **Карточка** `/agent/candidates/[id]`: текст черновика AI только текстом, находки проверки подсвечены, обращения-источники ссылками для сотрудника, ближайшее опубликованное решение по вектору с процентом сходства, три действия решения 29.
3. **"Сделать черновиком решения"**: одна транзакция сотрудника: решение-черновик с аудиторией `internal`, текстом кандидата в заготовке из трёх блоков, всеми источниками в `hdk_article_sources`, признаком `hdk_articles.is_untrusted`; кандидат `accepted`; журнал `solution.created_from_candidate` и `candidate.accepted`. Редактор открывается сразу.
4. **"Объединить с решением"**: источники добавляются к действующему решению по номеру, кандидат `merged`, `staff_useful_count` растёт на число источников. **"Отклонить"**: причина из списка обязательна, комментарий необязателен, запоминается число источников для возврата на пятом новом.
5. **Недоверенный текст** (миграция `0107_hdk_untrusted_drafts.sql`, номер сдвинут на два от плана): у решения с `is_untrusted` находки телефона, почты, команды и кода (`findCommands`: sudo, rm, curl, wget, powershell, cmd, chmod, SQL drop, delete from, update ... set, truncate, insert into, alter table, grant, обратные кавычки и блоки кода) блокируют публикацию, пока каждая не отмечена. Отметки хранятся в версии (`untrusted_confirmed`: отпечатки находок и отпечаток текста); изменённый текст даёт другой отпечаток, отметки перестают действовать. Отметить можно отдельным действием (`confirmUntrustedFindings`) или галочками в окне публикации: публикация проверяет и записывает их в той же транзакции с журналом `solution.untrusted_confirmed`.
6. **Кандидат не в поиске**: подсказка клиента, панель виджета, поиск помощника и поиск сотрудника не находят текст кандидата ни до "Сделать черновиком", ни после; находят только после публикации решения обычным порядком (строка M5c 16.2).

## Цена

Отпечаток текста меняется при любой правке, даже не задевшей находку: сотрудник отмечает находки заново. Слово "delete" в английском тексте находкой не считается, а "delete from" считается; команда без характерной формы (например, `systemctl restart` без sudo) не находится.
