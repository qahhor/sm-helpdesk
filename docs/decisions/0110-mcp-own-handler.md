# 0110. Свой обработчик протокола MCP без новой зависимости

Дата: 27.11.2026. Веха M8b, задача 4; ТЗ 7.21 (FR-AGT-01, 02), 13 (`POST /api/mcp`); решения 3, 4, 30, 32 плана M8b. Статус: **решение владельца 27.11.2026**. Заменяет выбор библиотеки `@modelcontextprotocol/server`, который план предлагал под этим номером.

## Что решено

1. **Новой зависимости нет.** Сервер MCP разбирает JSON-RPC 2.0 своим кодом в `src/modules/hda/agent/server.ts`. Поддерживаются методы `initialize`, `notifications/initialized`, `tools/list`, `tools/call` и `ping`.
2. **Без состояния и только JSON.** Каждый `POST /api/mcp` проверяет токен заново, сессий MCP (`Mcp-Session-Id`) и потоков SSE нет. Ответ на запрос одним объектом `application/json`, на уведомление `202` без тела. `GET` и `DELETE` отвечают `405`.
3. **Версия протокола** согласуется по спецификации MCP: если клиент прислал поддерживаемую версию, сервер отвечает ею; иначе своей последней поддерживаемой, и клиент решает, продолжать ли. Поддерживаются ревизии спецификации 2025-11-25, 2025-06-18, 2025-03-26 и 2024-11-05.
4. **Ошибки JSON-RPC:** разбор -32700, неверный запрос -32600 (в том числе пакет запросов массивом), неизвестный метод -32601, неверные параметры -32602. Ошибки инструментов (не из перечня, неверные аргументы, предел, не найдено) отдаются результатом `tools/call` с `isError: true` и кодом из `HdaAgentError`, без текста исключений.
5. **Каждый запрос проверяется схемой Zod:** конверт JSON-RPC, параметры каждого метода и аргументы инструмента. Описания `inputSchema` и `outputSchema` в `tools/list` строит `z.toJSONSchema` из тех же схем.
6. **Тестовый клиент тоже свой** (`tests/helpers/mcp-client.ts`, решение 32 плана), пакета клиента MCP нет.
7. Интерфейс `McpHandler` отделяет разбор протокола от проверки токена и инструментов: если команда агентов позже попросит SSE или сессии, меняется только разбор.

## Цена

Новые ревизии спецификации MCP придётся добавлять вручную: клиент с версией новее получит ответ последней известной версией. Совместимость с настоящим Hermes Agent проверяется после получения профиля (раздел "Что заблокировано" плана).
