# 0112. Представления для агента и обезличивание

Дата: 27.11.2026. Веха M8b, задача 2; ТЗ 7.21 (FR-AGT-03, 06, 12, 14, 15), 14.3 "Внутренние агенты", угроза T27; решения 6, 7, 8, 15 плана M8b. Принято исполнителем по общему поручению владельца от 26.11.2026. Статус: принято исполнителем.

## Что решено

1. **Данные агента только через представления.** `hda_agent_tickets`, `hda_agent_messages`, `hda_agent_solutions`, `hda_agent_candidates`, `hda_agent_problems`, `hda_agent_ideas` (миграция 0110, `security_barrier`, владелец `hub_owner`). Каждое пусто для любого актора, кроме `agent` с действующим токеном. Базовые таблицы агенту закрыты (решение 0111). Владелец читает базовые таблицы политиками `*_owner_select` по образцу `hdp_problems_public`.
2. **Кого видит агент.** Обращения организаций клиентов с включённой AI-обработкой, без служебной "Неопознанные" (`app.agent_can_see_org`). Выключение AI-обработки убирает обращения со следующего запроса. Видимость `private` не мешает. Токен запуска видит только своё обращение и его сообщения; решения, кандидаты, проблемы и идеи для него пусты.
3. **Колонки.** Организация идентификатором и категорией A-D. Нет автора, исполнителя, контекста обращения, сервера, названия и ИНН организации, вложений и имён файлов. Авторы сообщений условным номером внутри вида в обращении (`author_no`). Сообщение помощника кодом вида и номером решения или проблемы.
4. **Переписка** (решение 7). Публичные сообщения, сообщения помощника, заметки агента и поля передачи на другую линию (причина кодом, "что проверено", "что требуется", пояснение). Внутренних заметок сотрудников нет. **Изменено решением владельца 27.11.2026 (решение 0114, миграция 0111):** внутренние заметки сотрудников видны агенту, обезличенными в полях `untrusted_*`.
5. **Кандидаты и идеи.** Кандидат с источником организации без AI-обработки не выдаётся целиком, источники только номерами обращений. Идеи только опубликованные, текст автора на языке оригинала, без автора и организации; идеи организаций без AI-обработки не выдаются.
6. **Обезличивание текста кодом.** Представление отдаёт свободный текст как есть: имена людей организации и сотрудников база не знает в виде правил. Перед ответом агенту текст проходит `anonymizeForAgent` (`src/modules/hda/agent/anonymize.ts`): почта `[email]`, телефоны `[телефон]`, ИНН, ПИНФЛ и длинные числа `[номер]` (правила `findInText` проверки решений), сервер клиента Smartup `[сервер]`, имена людей обозначениями "Клиент 1", "Сотрудник 1" в порядке появления, устойчивыми в пределах ответа, название и ИНН организации `[организация]`, невидимые знаки удаляются. Похожие обращения других организаций идут выдержкой `agentExcerpt` до 300 знаков (FR-AGT-15).
7. **Телефон короче 9 цифр** без разделителей правила проверки решений не ловят, а 7 и больше цифр подряд становятся `[номер]`. Суммы с пробелами ("1 250 000") остаются текстом.

## Цена

Прямой запрос агента к представлению отдаёт свободный текст до обезличивания: ограничение держится на том, что у агента нет доступа к базе, кроме сервера MCP (FR-AGT-01, `CLAUDE.md`). Номер телефона из 7-8 цифр с разделителями может остаться в тексте. Владелец `hub_owner` читает базовые таблицы для представлений.
