# 0115. Инструменты чтения сервера MCP

Дата: 27.11.2026. Веха M8b, задача 5; ТЗ 7.21 (FR-AGT-03, 06, 14, 15), 14.3 "Внутренние агенты"; решения 6-9, 17 плана M8b, решение 0114. Принято исполнителем по общему поручению владельца от 26.11.2026.

## Что решено

1. **Каталог чтения:** `search_tickets`, `get_ticket`, `similar_tickets`, `sla_risk_tickets`, `unsolved_signatures`, `search_solutions`, `get_solution`, `list_candidates`, `list_known_problems`, `list_ideas`, `assistant_metrics`; `signature_spikes` появляется с таблицей всплесков (задача 8). Каждый вход строгой схемой с пределами, каждый выход с постоянным полем `notice`.
2. **Строки отбирает база** представлениями `hda_agent_*`; код инструмента только обезличивает. Номер вне видимости агента отвечает `not_found`.
3. **Обезличивание ответа** (решение 8): слова (название и ИНН организаций ответа, имена их участников, имена сотрудников портала) читает система функцией `agentRedactionTerms` модуля `hdu` отдельной транзакцией; агенту они не уходят. Обозначения "Клиент 1", "Сотрудник 1" устойчивы в пределах одного ответа. Тексты решений, кандидатов, идей, проблем и образцы ошибок обезличиваются общими правилами (почта, телефоны, номера, сервер) без списка имён: у этих объектов нет одной организации.
4. **Тексты людей только в `untrusted_*`:** клиент в `untrusted_customer_text`, сотрудник, помощник, агент, система, решение, кандидат, проблема в `untrusted_text`. Авторы сообщений условные: `client:1`, `staff:2`, `ai`, `agent`, `system`. Внутренние заметки сотрудников видны с видом `internal_note` (решение 0114), заметки агента `agent_note`.
5. **Сигнатуры ошибок** отдаёт новое представление `hda_agent_signatures` (миграция 0112): счётчики по всем организациям без разбивки, образец текста ошибки только если все организации сигнатуры видны агенту.
6. **Похожие обращения** без расширения `pg_trgm` (в базе его нет): сначала та же сигнатура, затем тот же модуль с общими словами темы (от 4 букв), не больше 10. Выдержка описания 300 знаков после обезличивания у всех организаций.
7. **Риск SLA:** открытые обращения, у которых нарушен или наступит в ближайшие N часов (1-72) срок первого ответа или решения; нарушенные первыми, затем по ближайшему сроку. Пауза "Ждём вашего ответа" не исключает обращение: срок в базе уже сдвинут паузой.
8. **Показатели помощника** считает система функцией `assistantMetricsForAgent` модуля `hdt` теми же правилами, что `/agent/metrics`, за период "с даты по дату"; только числа.

## Цена

Имена людей не из организации обращения и не из сотрудников (например, имя партнёра клиента) обезличивание не узнаёт. Похожие обращения без `pg_trgm` грубее: близкая тема другими словами не найдётся. Число в `assistant_metrics` считается по всем организациям, включая организации без AI-обработки (это числа без данных).
