# 0117. Токен запуска по обращению

Дата: 27.11.2026. Веха M8b, задача 7; ТЗ 7.21 (FR-AGT-12, 13), угроза T35, поправка 101; решения 15, 27 плана M8b. Принято исполнителем по общему поручению владельца от 26.11.2026.

## Что решено

1. **Выпуск** `issueTicketRunTokenTx` (`src/modules/hda/agent/run-token.ts`) только системой, в транзакции отправки события (задача 9): строка `hda_agent_tokens` с родителем и обращением, перечень ровно `get_ticket` и `add_internal_note`, одна заметка, срок 2 часа, адреса, суточный предел и учётная запись родителя. Значение возвращается вызывающему один раз, в базе хеш.
2. **Повторный выпуск** по тому же основному токену и обращению отзывает прежний токен запуска той же транзакцией.
3. **Видимость** держит база: представления отдают токену запуска только его обращение, остальные пусты; политика вставки заметки пускает только в его обращение.
4. **Одна заметка** до 2000 знаков: длину проверяет инструмент, число считает триггер базы под блокировкой строки токена, поэтому из двух одновременных вызовов проходит один, второй получает `note_limit`.
5. **Срок и отзыв:** через 2 часа, после отзыва родителя и после повторного выпуска следующий запрос получает 401 (функция `app.agent_token_active()`); `revokeTicketRunTokenTx` отзывает токен запуска системой.
6. **Текст-атака** в обращении отдаётся только в `untrusted_customer_text`; у токена нет инструмента сводки, чата, поиска и черновиков, вызов даёт `tool_not_allowed`.

## Цена

Токен запуска живёт 2 часа после отправки события, даже если агент закончил раньше: отзыв по завершении работы агента не предусмотрен протоколом. Предел 20 вызовов за срок считается отдельно от суточного предела родителя.
