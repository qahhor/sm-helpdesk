# 0120. Раздел "Сводки" и сообщение в чат команды

Дата: 27.11.2026. Веха M8b, задача 10; ТЗ 7.21 (FR-AGT-04, 07, 13), 8.12 "Сводки", 10.5; решения 22-24 плана M8b. Принято исполнителем по общему поручению владельца от 26.11.2026.

## Что решено

1. **Раздел `/agent/digests`** по образцу "Список": дата, вид, автор "AI-сотрудник", пометка "AI-сотрудник, не проверено" или "Просмотрено"; фильтр вида и пометки, страницы по 50. Видят все сотрудники (пункт меню "Сводки" в группе "Аналитика", веха `M8b` включена). Клиент не читает ни одной строки.
2. **Карточка** `/agent/digests/[id]`: текст агента обычным текстом, период, числа и номера обращений ссылками портала, кнопка "Просмотрено". Отметка от имени сотрудника, журнал аудита `agent.report_reviewed` той же транзакцией; повтор ничего не меняет.
3. **Сообщение в чат команды** (решение 24): портал собирает его по шаблону `agent.teamChat` из `messages/*.json` (вид сводки, числа по ключам `new_tickets`, `ai_resolved`, `handed_off`, `sla_risk`, номера обращений ссылками, ссылка на сводку) и отправляет ботом сотрудников (`TELEGRAM_BOT_TOKEN`) в чат из настройки `agent.team_chat_id`. Текст и заголовок агента у функции на входе нет. Отправка в минутной задаче `agent.events_dispatch` по сводкам за последние сутки; отметка `chat_sent_on` (миграция 0116, ставит только система, один раз) не даёт повтора. Нет настройки или бота: сообщения нет, сводка сохраняется.
4. Номера обращений вне видимости агента отбрасываются уже при записи сводки (задача 6); ключи вне перечня отклоняет схема инструмента.

## Цена

Сообщение уходит на русском: язык чата команды не настраивается. Сводки старше суток после включения чата в чат не уходят. При сбое бота сообщение не повторяется: отметка ставится до отправки, чтобы два процесса не отправили его дважды.
