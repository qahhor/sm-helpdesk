# 0121. Приёмка вехи M8b

Дата: 27.11.2026. Веха M8b, задача 11; строка M8b раздела 16.2, строки 15.2 "Сервер MCP отдаёт обращение агенту" и "Агент вызывает инструмент вне перечня токена", сценарий 19 раздела 15.3. Принято исполнителем по общему поручению владельца от 26.11.2026.

## Что решено

1. **Приёмка по строке 16.2** привязана к тестам (таблица в `docs/plans/M8b-report.md`, раздел "Приёмка"): чтение обращения без контактов и заметка (`tests/e2e/agent-mcp-s19.spec.ts`, `tests/integration/hda-agent-read-tools.test.ts`, `tests/integration/hda-agent-write-tools.test.ts`), отказ вне перечня с журналом (`tests/integration/hda-mcp-server.test.ts`), отзыв со следующего запроса (`tests/integration/hda-mcp-server.test.ts`, `tests/integration/hda-agent-run-token.test.ts`, `tests/e2e/agent-mcp-s19.spec.ts`).
2. **Планы запросов** на наборе 10000 обращений (`tests/integration/hda-agent-plans.test.ts`): обращение по номеру берётся индексом номера, список, поиск по теме и сигнатуре, похожие и риск сроков укладываются меньше чем в секунду при пределе 5 секунд. Отдельная миграция индексов не понадобилась.
3. **Независимая проверка** ветки по разделу "На что смотреть при проверке" плана за владельцем: её итог и исправления записываются в отчёт вехи, раздел "Независимая проверка", и дополняют это решение.

## Цена

До независимой проверки приёмка держится только на тестах исполнителя. Проверка с настоящим Hermes Agent ждёт его профиля.
