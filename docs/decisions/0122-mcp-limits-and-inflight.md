# 0122. Пределы и версии сервера MCP после независимой проверки

Дата: 27.11.2026. Веха M8b, независимая проверка, находки I3, I4 и M8; ТЗ 7.21 (FR-AGT-09), 14.5; решение 12 плана M8b, решение 0110. Принято исполнителем по общему поручению владельца от 26.11.2026.

## Что решено

1. **Минутный предел** 60 в минуту на токен считает каждый `tools/call`, и разрешённый, и вне перечня: счётчик стоит до проверки перечня. Вызов сверх предела отклоняется `rate_limited` без записи аудита; в журнал вызовов идёт одна строка `rate_limited` за минуту на токен (счётчик `agentRateLimitedLog`), остальные отказы только в журнал работы.
2. **Суточный предел** токена и 20 вызовов за срок у токена запуска считают только вызовы инструментов из перечня, как прежде: решение "пределы считают `tools/call`" сохраняется, к нему добавлен счёт отказов вне перечня в минутном пределе.
3. **Методы протокола** (`initialize`, `tools/list`, `ping`, уведомления, неизвестные методы) отдельным пределом 120 в минуту на токен. Сверх него HTTP 429 с `Retry-After` и ошибкой JSON-RPC -32000 `Too many requests`, у уведомления без тела.
4. **Одновременные вызовы** `tools/call` в процессе не больше `MCP_MAX_INFLIGHT` (схема окружения, 1-32, по умолчанию 4). Сверх него тот же ответ 429 с `Retry-After: 1`; вызов не выполняется и в журнал вызовов не пишется. Счётчик в памяти процесса, у каждой копии портала свой.
5. **Одно соединение на вызов:** транзакция актора `agent` не открывает внутри себя других. Адреса для ссылок и показатели помощника система читает до неё (`prepare` инструмента), слова обезличивания после неё (отложенный ответ `finish`), строка журнала вызова чтения пишется второй короткой транзакцией агента. У инструментов записи строка журнала и аудит в одной транзакции с записью, как прежде.

## Цена

Агент, который зациклился на отказах, через минуту получает `rate_limited` и на разрешённые инструменты. Строка журнала вызова чтения пишется отдельной транзакцией после ответа: при сбое базы между ними агент получает `internal`, а строка журнала пишется системой со статусом `error`. Предел одновременных вызовов на процесс, а не на токен: два агента делят его.

Тесты: `tests/integration/hda-mcp-server.test.ts` (тесты с пометкой "находка I3" и "находка I4"), `tests/unit/hda-mcp-protocol.test.ts` (согласование версии).
