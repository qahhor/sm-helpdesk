# 0124. Токен запуска не шире основного токена

Дата: 27.11.2026. Веха M8b, независимая проверка, находка I5; ТЗ 7.21 (FR-AGT-12), 14.2 (T35); решение 15 плана M8b, решение 0117. Принято исполнителем по общему поручению владельца от 26.11.2026.

## Что решено

1. **Перечень при выпуске:** пересечение `get_ticket`, `add_internal_note` с перечнем основного токена. Основной токен без `get_ticket` токена запуска не получает (`issueTicketRunTokenTx` возвращает null), событие уходит без `run_token`. Тело события перечисляет выпущенный перечень.
2. **Каждый запрос:** вход сервера MCP проверяет адрес и по списку токена запуска, и по текущему списку основного токена, а перечень токена запуска сужает до текущего перечня основного. Правка основного токена на экране "AI-сотрудники" действует на его токены запуска со следующего запроса; отдельной миграции не нужно, функция базы `app.agent_token_active()` не менялась.

## Цена

Расширение перечня основного токена на уже выпущенный токен запуска не действует (его перечень записан при выпуске); следующий токен запуска получит новый перечень.

Тесты: `tests/integration/hda-agent-run-token.test.ts` (тесты "находка I5").
