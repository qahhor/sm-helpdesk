# 0126. Таблицы знаний из кода и доступ к ним

Дата: 27.11.2026. Веха M8c, задача 1; ТЗ 7.22 (FR-CODE-02, 04, 05, 11, 12), 10.5, 5.2; решения 1, 6-9, 12, 25 плана M8c. Принято исполнителем по общему распоряжению владельца от 26.11.2026.

## Что решено

1. **Имена.** `hda_code_scans`, `hda_code_error_entries`, `hda_code_error_templates`, `hda_code_module_notes`, `hda_code_analysis_requests`, представление `hda_code_checks`; колонки `scan_key`, `commit_ref`, `received_on`, `finished_on` по `docs/naming.md`; у запроса анализа первой колонкой `org_id`.
2. **Выражение строит база.** Генерируемая колонка `hda_code_error_templates.pattern` = `app.hda_code_pattern(template)`: подстановки `{name}` в группы `(.{1,200}?)`, остальное буквально, пробелы как `\s+`, выражение на всю строку, в конце допускается точка или "!". Записать колонку нельзя; шаблон одной строкой без обратной косой черты (проверка базы).
3. **Сигнатура из ключа.** Генерируемая колонка `hda_code_error_entries.signature` = первые 32 знака sha256 от `code-key|<ключ>` (функция `app.hda_code_key_signature`): тот же вид, что у сигнатур 11.5, поэтому решения, проблемы, всплески и правила работают с ней без изменений.
4. **Сигнатура по шаблонам** для любого актора только функцией `app.hda_code_signature(code, lines)` с правами владельца: она отдаёт сигнатуру утверждённой записи или пусто. Системный актор (AI-помощник, подсказка, Тез, правила) записей, шаблонов и заметок о модулях не читает.
5. **Доступ.** Читают `agent_l2`, `care`, `admin` (`app.hda_code_reader()`); первая линия только `hda_code_checks` (ключ, сигнатура, модуль, "что проверить" утверждённых); `product` и клиент ничего. AI-сотрудник читает каталог основным токеном и токеном запуска, пишет основным; триггер не даёт ему утвердить, отклонить или задать утвердившего. Сотрудник меняет только поля правки и статус и утверждает от своего имени. Заметку о модуле решает только администратор. Запрос анализа создаётся ожидающим от имени создателя; агент только отвечает (в `done`), система только ставит `timeout`.
6. **Набор изоляции.** Новые виды доступа агента `code-catalog` и `code-requests`: общий тест проверяет, что агент ничего не удаляет (кроме шаблона языка основным токеном) и видит запросы только организаций с AI-обработкой; подробности в `hda-code-access.test.ts`.

## Цена

Поля генерируются после триггеров `BEFORE`, поэтому сравнение полей в триггере защиты не учитывает `signature`. Если ключ записи когда-нибудь потребуется менять, сигнатура сменится вместе с ним: ключ поэтому не меняет ни агент, ни сотрудник.

Тесты: `tests/integration/hda-code-access.test.ts`, `tests/integration/isolation/registry.test.ts`.
