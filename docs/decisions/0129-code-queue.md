# 0129. Очередь "Знания из кода", карточка записи и карта модулей

Дата: 27.11.2026. Веха M8c, задача 4; ТЗ 7.22 (FR-CODE-03, 13, 15), FR-ADM-15, 8.12; решения 9, 14, 23, 24, 26 плана M8c. Принято исполнителем по общему распоряжению владельца от 26.11.2026.

## Что решено

1. **Страницы.** `/agent/code-knowledge` (очередь: по умолчанию черновики, новые и изменённые первыми и с меткой "Новое" или "Изменено", показатель пользы за 30 дней), `/agent/code-knowledge/[ключ]` (карточка: шаблоны по языкам, условия, причина, что проверить, место в коде ссылкой "объект, файл, строка", сканирование; "Утвердить", "Править", "Отклонить" с необязательной причиной), `/agent/code-knowledge/scans` (история: дата, репозиторий, версия, числа или правила отклонения), `/agent/code-knowledge/modules` (заметки о модулях и чем они отличаются от справочника). Пункт меню "Знания из кода" в группе "Знания" для `agent_l2`, `care`, `admin`; другим ролям страница отвечает "не найдено".
2. **Решения по записи.** Утвердить можно черновик и отклонённую, отклонить черновик и утверждённую; исчезнувшую из кода нельзя ни то, ни другое. Повтор ничего не меняет. Утверждающий берётся из актора. Правка меняет условия, причину, что проверить, род и шаблоны по тем же правилам, что у отчёта (решение 0127), статус не меняется. Журнал аудита `code.entry_approved`, `code.entry_rejected`, `code.entry_edited` той же транзакцией, в описании ключ записи полем `entry`.
3. **Заметки о модулях.** "Применить к справочнику" и "Отклонить" только администратору со свежим входом (как другие изменения справочника). Применение создаёт модуль с названием из отчёта или заменяет список экранов существующего модуля; название существующего модуля не меняется. Журнал аудита `code.module_approved` (с итогом `created`, `updated`, `same`) и `code.module_rejected`.
4. **Показатель пользы** (FR-CODE-15): обращения клиентов с сигнатурой ошибки за 30 суток (без "Неопознанных" и объединённых) и сколько из них с сигнатурой записи каталога; число решений из записей добавляет задача 6.

## Цена

Состояние "утверждено" не хранит, кто правил запись после утверждения: это видно только в журнале аудита. Справочник модулей меняется целым списком экранов: правка экранов администратором вручную будет заменена при следующем применении заметки.
