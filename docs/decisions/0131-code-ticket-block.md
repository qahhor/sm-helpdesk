# 0131. Блок "Что известно по коду" и решение из записи

Дата: 27.11.2026. Веха M8c, задача 6; ТЗ 7.22 (FR-CODE-06, 07, 11, 15), FR-SOL-04, 8.12; решения 16, 17 плана M8c. Принято исполнителем по общему распоряжению владельца от 26.11.2026.

## Что решено

1. **Блок в правой колонке обращения** под блоком известной проблемы. `agent_l2`, `care`, `admin`: утверждённая запись, чья сигнатура совпала с сигнатурой обращения, и записи (утверждённые и черновики), чьи шаблоны совпали со строками обращения, до пяти; у черновика пометка "не проверено", у утверждённой "утверждено"; условия, что проверить, место в коде ссылкой, ссылка на запись. `agent_l1`: только "Что проверить" утверждённой записи по сигнатуре обращения (представление `hda_code_checks`). `product`: блока нет. Совпадение шаблона в блоке то же, что у сигнатуры: строка целиком, с учётом кода ошибки.
2. **"Создать решение из записи"** у утверждённой записи для ролей черновиков решения из числа читающих знания (`agent_l2`, `care`, `admin`). Черновик `internal` с признаком недоверенного текста: заголовок из шаблона на языке сотрудника, подстановки заменены многоточием; "Проблема" из причины у пользователя; шаги из "что проверить". Ключ, код ошибки, условия и место в коде в черновик не попадают. Сигнатура записи привязывается к решению, если её не ведёт другое решение (тогда черновик создаётся, редактор показывает подсказку). Журнал аудита `solution.created_from_code`. Колонка `hdk_articles.code_entry_id` (миграция 0120).
3. **Проверка перед публикацией** (FR-SOL-04) решения из записи ищет, кроме общих правил внутренних имён, ключ, объекты и их части, пути и имена файлов записи (находка `internal`, подсвечивается, публикация с подтверждением).
4. **Показатель** "решений создано из записей" считается по `code_entry_id` за 30 суток.

## Цена

Имена записи для проверки читаются правами сотрудника, который смотрит проверку: у первой линии (знаний из кода она не видит) остаются только общие правила внутренних имён. Блок не показывает записи по сигнатуре 11.5, совпавшей со строкой без шаблона.
