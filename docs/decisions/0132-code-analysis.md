# 0132. "Разобрать по коду": запрос, событие, инструменты агента, срок

Дата: 27.11.2026. Веха M8c, задача 7; ТЗ 7.22 (FR-CODE-08, 10), 7.21 (FR-AGT-08, 12); решения 18-21 плана M8c. Принято исполнителем по общему распоряжению владельца от 26.11.2026.

## Что решено

1. **Запрос.** Кнопка "Разобрать по коду" в блоке "Что известно по коду" у `agent_l2`, `care`, `admin`. Запрос (`pending`, срок через 10 минут), событие предметной области `code_analysis_requested` с идентификатором запроса и журнал аудита `code.analysis_requested` одной транзакцией. Пока запрос ждёт, повтор возвращает его же (уникальный индекс на ожидающий запрос обращения, гонка двух нажатий читает запрос первого). Организация без AI-обработки и "Неопознанные": кнопки нет, объяснение в блоке, сервер отвечает `ai_disabled`.
2. **Событие агенту.** Разбор событий ставит событие очереди `hda_agent_events` (вид зарезервирован в M8b). Тело только из кодов и идентификаторов, как у других событий, плюс `analysis_request.id`. Правила автоматизации на это событие не срабатывают.
3. **Токен запуска анализа** (если отмечен токен "для событий"): `get_ticket`, `search_code_catalog`, `submit_code_analysis`, не шире перечня родителя, одна заметка, 2 часа.
4. **Инструменты.** `search_code_catalog` (чтение): по ключу, сигнатуре, модулю или словам, до 20 черновиков и утверждённых записей, тексты в `untrusted_text`, шаблоны без выражений. `submit_code_analysis` (запись): портал собирает внутреннюю заметку вида `code_analysis` из полей (гипотеза, уверенность, места в коде ссылками, что проверить у клиента, вопросы клиенту, похожие обращения номерами, рекомендация, ключи записей) с постоянными заголовками на русском; любое поле больше 10 строк отклоняется (`invalid_arguments`), текст очищается как заметка M8b. Заметка закрывает последний запрос обращения (`done`, ссылка на заметку). Без запроса ответ не принимается (`not_found`).
5. **Срок** (FR-CODE-10). Минутная задача `agent.events_dispatch` заодно ставит `timeout` ожидающим запросам, срок которых вышел; блок показывает "анализ не выполнен" и сам по сроку. Поздний ответ принимается и закрывает запрос `done`. Работа с обращением от анализа не зависит.
6. **Заметка анализа** видна только сотрудникам с пометками "AI-сотрудник, не проверено" и "Анализ по коду". Она не меняет статус, исполнителя, сроки, "клиент ждёт с" и не ставит уведомлений.

## Цена

Без отмеченного токена "для событий" событие уходит без токена запуска: агент отвечает основным токеном с `submit_code_analysis`. Несколько поздних ответов основным токеном дают несколько заметок; запрос ссылается на первую.

Тесты: `tests/integration/hda-code-analysis.test.ts`, `tests/unit/hda-code-note.test.ts`.
