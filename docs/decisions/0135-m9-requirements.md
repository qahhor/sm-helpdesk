# 0135. Перечень требований раздела 7 и проверка fr-coverage

Дата: 27.11.2026. План: `docs/plans/M9.md`, задача 1, решение 21. Статус: принято исполнителем по общему поручению владельца от 26.11.2026; согласие на перенос дают ответом по отчёту вехи.

1. **Перечень `docs/plans/M9-requirements.md` закрывает пункт 1 условий 15.5 в части "реализованы или перенесены".** 291 код FR разделов 7.1-7.22: сделано 190, сделано на заглушке 99, перенесено 2 (FR-AUTO-12 частично, решение 0043, пункт 10; FR-I18N-08 частично, решение 0160, пункт 4). Пересчёт 28.11.2026 (волна 7, T3): проверка `fr-coverage` искала имя раздела только из букв и не видела десять кодов FR-I18N раздела 7.11; до пересчёта было 281 код, 182, 98 и 1.
2. **"Сделано на заглушке"** ставится требованиям, у которых вместо внешнего сервиса ложный сервер или заглушка: модель Claude, OIDC Smartup, сборка Smartup Web, Resend, Telegram, Hermes Agent, API таск-менеджера. Они работают в среде разработки, но пункт 15.5, который проверяет их с настоящим сервисом, остаётся "ждёт".
3. **Доказательство.** Тест, где код требования назван прямо; для 79 кодов, которых тесты не называют, тест той области, что требование проверяет. Проверка не может доказать, что выбранный тест действительно проверяет требование: это остаётся за проверяющим вехи.
4. **Проверка `fr-coverage` в `pnpm check`:** нет кода из ТЗ (`missing`), лишний код (`unknown`), "сделано" без пути в `tests/` (`no_evidence`), "перенесено" без решения (`no_decision`), ссылка на несуществующий файл (`dead_link`), состояние не из трёх (`bad_state`, сверх плана: опечатка в состоянии иначе прошла бы молча).

Цена ошибки: если тест области не покрывает требование, перечень показывает "сделано" для непроверенного. Исправление: дописать тест и поправить строку.
