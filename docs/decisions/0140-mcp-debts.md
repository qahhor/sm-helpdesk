# 0140. Долги сервера MCP перед выпуском токена

Дата: 27.11.2026. План: `docs/plans/M9.md`, задача 7, решение 22; долги `docs/plans/M8b-report.md` M1, M4, M5, M7, M9. Статус: принято исполнителем по общему поручению владельца от 26.11.2026.

1. **M4: журнал аудита токена запуска.** Выпуск пишет `agent.run_token_issued` (основной токен, обращение, назначение, перечень), отзыв `agent.run_token_revoked` с причиной `replaced` (новое событие по тому же обращению) или `not_sent` (событие не ушло), той же транзакцией, что строка токена. План просит запись "от агента"; политика журнала аудита пишет актора транзакции и другого не принимает, а токен выпускает система при отправке события. Ослаблять политику нельзя (`CLAUDE.md`), поэтому действует система, объект записи токен запуска, основной токен назван в описании. Отказы вне перечня по-прежнему пишет система до транзакции инструмента: менять это значит давать агенту запись в журнал вызовов, а это шире долга.
2. **M9: одинаковый ответ.** Адрес вне списка токена, основного токена или `MCP_ALLOWED_IPS` отвечается тем же 401 с `WWW-Authenticate: Bearer` и тем же телом, что неверный токен. Причину различают журнал вызовов (строка `connect` со статусом `refused`) и событие `mcp.denied` с `reason`. Отказ по адресу в счётчик неудачных проверок токена не идёт: у действующего токена с чужого адреса это не перебор токенов.
3. **M7: поиск по обезличенной теме.** `search_tickets` с текстом отбирает до 500 самых новых обращений остальными фильтрами, обезличивает темы и только потом сверяет текст без учёта регистра. Имя человека из темы не находится. Цена: текст ищется только среди этих 500, о чём сказано в описании инструмента и в инструкции агентам.
4. **M1: суточный предел родителя.** Вызовы токена запуска расходуют суточный счётчик основного токена; исчерпанный основной токен отказывает и своим токенам запуска. Предел 20 вызовов на токен запуска остаётся.
5. **M5** описан в `docs/guides/agents.ru.md`, раздел 7: новое событие по тому же обращению отзывает прежний токен запуска того же назначения, агент работает по последнему событию.

Остальные долги M8b (M11-M14) и M8c (M6, M8) остаются с прежними причинами: прав они не касаются.
