# 0142. Сценарии проверки сервера, почты и замера по HTTP

Дата: 27.11.2026. План: `docs/plans/M9.md`, задача 10, решения 14, 16, 18; ТЗ 13.9, 13.10, 15.1, 15.5 пп. 6, 7. Статус: принято исполнителем по общему поручению владельца от 26.11.2026.

1. **`scripts/ops/server-audit.mjs`** только читает: `sshd_config` и `sshd_config.d` (первое значение вне `Match`, как у sshd), `20auto-upgrades`, `docker inspect` запущенных контейнеров. Пункты: пароль и root по SSH выключены, вход по ключу, обновления безопасности, наружу только 80 и 443, образы по digest, службы портала (`web`, `web2`, `worker`, `migrate`, `bootstrap`) не от root, они и `tei`, `typesense` с файловой системой только для чтения, Caddy только для адресов Cloudflare. У `caddy`, `postgres`, `clamav` root и запись допускаются "исключением" с причиной: так их задаёт `compose.prod.yaml`. Значения переменных окружения контейнеров читаются, но не печатаются. Правила сетевого экрана хостинга с сервера не видны: их проверяют в кабинете хостинга по памятке (раздел 1). Ключ `--dir` читает файлы-образцы.
2. **`scripts/ops/mail-dns-check.mjs`** (`node:dns`): SPF Resend на `send.<домен отправки>` (только `include:amazonses.com`, завершение `~all` или `-all`, одна запись), ключ DKIM `resend._domainkey`, DMARC с политикой и `rua`, MX домена приёма и MX обратной связи. `p=none` предупреждение, а не ошибка: памятка разрешает её первый месяц. Доставка в ящики и подделка DMARC проверяются руками (раздел 11 памятки).
3. **`scripts/ops/http-probe.mjs`**: прогрев 5, затем 40 запросов по очереди, p50 и p95 методом ближайшего ранга. Пороги p95: страницы клиента 300 мс (аудит, раздел 4.3), страницы рабочего места 600 мс (у запроса очереди своя цель 50 мс, её мерит `tests/perf/pilot-p95.test.ts`), подсказка 500 мс (FR-SOL-14) строкой списка. Строка с ответом не 2xx не держится. Работает только с `--target staging`; адрес из `HUB_PRODUCTION_URL` и `hub.smartup24.com` отклоняются. Куки и токен берутся из переменных окружения и в вывод не попадают. Подсказка требует токена виджета, поэтому в список по умолчанию не входит.
4. **Порядок "сначала тест" нарушен для `server-audit.mjs`**: сценарий написан до теста, тест проверен после (запись в ведомости); для `mail-dns-check.mjs` и `http-probe.mjs` тесты падали до кода.

Цена ошибки: сценарий проверки сервера может не знать особенностей образа хостинга (другой путь `sshd_config`); тогда пункт даёт "нет", и администратор сверяет его руками.
