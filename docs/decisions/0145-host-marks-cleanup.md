# 0145. Обязательное имя сервера и очистка отметок ресурсов

Дата: 27.11.2026. Независимая проверка части A вехи M9, находка M2. Связано с решением 0141.

1. **`--host` обязателен.** `hub ops:host-mark` без `--host` отвечает кодом 2. Раньше имя по умолчанию бралось из `hostname()` процесса, а внутри контейнера `web` это имя контейнера: после каждого пересоздания появлялась новая строка, а прежняя давала `host_mark_stale` без конца. Сценарий `scripts/ops/host-watch.sh` и так передаёт имя сервера сам. Имя проверяется прежним правилом: строчные латинские буквы, цифры, точка и дефис, до 63 знаков.
2. **Отметки старше 7 суток удаляет ночная очистка** (`maintenance.cleanup`, функция `cleanupHostMarks` модуля hdc) под системным актором. Снятый или переименованный сервер даёт `host_mark_stale` не дольше недели: этого хватает, чтобы дежурный заметил и разобрался. Миграция 0128 добавляет роли `hub_app` только право DELETE; политика `hdc_ops_host_marks_system_all` прежняя и пускает к таблице только системного актора. Строка теста изоляции обновлена: `app: IUD`.
3. Цена ошибки: если сервер молчит больше 7 суток, его строка исчезнет и сигнал прекратится. Это видно по внешней проверке доступности и по журналу ночной очистки (`отметки ресурсов серверов старше 7 суток N`).
