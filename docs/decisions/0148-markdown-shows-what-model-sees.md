# 0148. Сотрудник видит на экране всё, что уходит модели и агенту

Дата: 28.11.2026. Проверка на AI-инъекции, волна 7, находка S-I1. Уточняет раздел 14.3 ТЗ ("Markdown без HTML").

1. **Что было.** Компонент `Markdown` пропускал разметку HTML (`skipHtml`), а определения сносок `[1]: адрес "текст"` библиотека не выводит. Клиент мог спрятать в комментарии HTML, блоке `<div>` или сноске указание для модели: сотрудник его не видел, а модель и агент получали как текст.
2. **Решение.** Меняется экран, а не вход модели: разметка HTML показывается текстом (у `react-markdown` 10.1.0 без `rehype-raw` она не исполняется, это проверяет тест), определение сноски показывается абзацем сразу после себя, подпись ссылки и картинки в кавычках (`title`) показывается текстом рядом. Требование 14.3 "HTML не исполняется" сохранено: тегов из текста в странице нет.
3. **Почему не вырезать из входа модели.** Вырезание по правилам разметки пришлось бы держать в точном согласии с библиотекой показа; расхождение снова дало бы скрытый текст. Одно правило "экран показывает исходный текст" расхождений не допускает.
4. **Тесты.** `tests/unit/markdown.test.tsx` (комментарий, блок, сноска, подпись), `hda-agent-read-tools.test.ts` (агент и экран видят одно и то же), категория `hidden_markdown` набора атак.
5. Цена ошибки: сообщение с разметкой HTML выглядит на экране сотрудника как текст с тегами. Это честнее пропуска.
