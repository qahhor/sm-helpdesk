# 0152. Сервер MCP: свободная строка из базы только под ключом untrusted_*

Дата: 28.11.2026. Проверка на AI-инъекции, волна 7, находки S-M2 и S-M3. Уточняет решение 9 плана M8b и решение 0114.

1. **Правило.** В ответе любого инструмента свободная строка лежит под ключом `untrusted_*`. Вне его допустимы только: постоянный текст `notice`; значения закрытых перечней (статус, приоритет, очередь, язык и подобные); идентификаторы строгого вида, которые строит портал или проверяет схема при записи (сигнатура, обозначение автора "client:1", код ошибки каталога, ключ сканирования); коды модулей справочника.
2. **Что перенесено.** `search_code_catalog`: `key`, `raised_in`, `templates` стали `untrusted_key`, `untrusted_raised_in`, `untrusted_templates` (текст пришёл из отчёта агента о коде). `list_ideas`: `released_in` стал `untrusted_released_in` (пишет сотрудник). `unsolved_signatures`: `sample_code` стал `untrusted_sample_code` (код ошибки приходит из текста клиента или контекста виджета). Это смена контракта трёх инструментов: агент читает схему ответа из `tools/list`, в `docs/` контракт обновлён этим решением.
3. **Что оставлено.** Коды модулей (`module`, `modules`) остаются вне `untrusted_*`: справочник ведёт администратор, код служит агенту значением фильтра. Перенос потребовал бы переписать вход и выход всех инструментов с фильтром по модулю.
4. **Тест.** `tests/unit/hda-agent-catalog.test.ts` обходит схему ответа каждого инструмента: свободная строка вне `untrusted_*` с именем не из перечня разрешённых роняет тест.
5. **Образец текста ошибки (S-M3).** `unsolved_signatures` отдаёт `sample_message` шаблоном раздела 11.5 (числа, значения в кавычках и идентификаторы заменены) и обезличенным по всем организациям, у которых сигнатура встречалась (`hdk_signature_orgs`): слова обезличивания читает система после транзакции агента, как у остальных инструментов чтения.
6. Цена ошибки: внешний агент, который читал старые имена полей, перестаёт их находить. Агент пилота ещё не подключён (веха M9, часть B).
