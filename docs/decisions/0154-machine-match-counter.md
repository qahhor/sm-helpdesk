# 0154. Совпадение черновика модели с решением считается отдельно от "пригодилось сотрудникам"

Дата: 28.11.2026. Проверка на AI-инъекции, волна 7, находка S-M8. Уточняет FR-CAND-03 и решение 28 плана M5c. **Пометка владельцу:** текст FR-CAND-03 ("у решения растёт счётчик "пригодилось сотрудникам"") расходится с этим решением, строка внесена в перечень правок `docs/TZ-1.2-changes.md`.

1. **Что было.** Ночная задача кандидатов увеличивала `hdk_articles.staff_useful_count`, когда черновик модели по закрытому обращению оказывался похож на опубликованное решение. Человек в этом не участвовал: текст обращения клиента через черновик модели менял число, которое сотрудники читают как оценку решения.
2. **Решение.** Совпадение без человека считает новая колонка `hdk_articles.machine_match_count` (миграция 0130). `staff_useful_count` растёт только от действия сотрудника: объединение кандидата с решением (FR-CAND-04). Кандидат при совпадении по-прежнему не создаётся.
3. **Показ.** Новый счётчик пока хранится и на экраны не выведен: в списке решений остаётся "пригодилось сотрудникам". Вывести его рядом можно отдельной задачей, если владелец захочет видеть оба числа.
4. Цена ошибки: число "пригодилось сотрудникам" у решений растёт медленнее, чем описано в FR-CAND-03. Накопленные до миграции значения не пересчитываются: разделить их на "с человеком" и "без" по данным нельзя.
