# 0157. Нулевой байт на границе базы и ответ модели, повторяющий системную подсказку

Дата: 28.11.2026. Проверка на инъекции, волна 7, находка S-T (расширение тестов нашло два пробела в коде).

1. **Нулевой байт.** Строка с U+0000 в поле поиска или текста роняла запрос ошибкой базы 22021 (в jsonb 22P05) в 17 входах: поиск обращений, решений, идей, известных проблем, кандидатов, людей, организаций, шаблонов, очередь, сохранённые фильтры, список решений, журнал аудита, два инструмента MCP. Это не инъекция (значение уходит параметром), но ответ 500 вместо обычного. PostgreSQL этот знак в тексте не хранит, поэтому он убирается из параметров запроса на границе базы, один раз для обоих пулов (`src/db/no-nul.ts`). Текст запроса не трогается. Текст поиска сохранённого фильтра (jsonb) дополнительно проходит `cleanUserText`.
2. **Почему не в схемах Zod.** Точек разбора входа больше двадцати; пропуск одной возвращает ошибку 500. Граница базы одна. Правило "каждая точка входа проверяет данные схемой" остаётся в силе: схемы проверяют смысл, граница убирает знак, который нельзя сохранить.
3. **Пересказ системной подсказки.** Ответ модели, в любой строке которого есть шесть слов подряд из системной подсказки этого вызова, не принимается (`prompt_echo` в журнале вызовов, как ответ не по схеме): фразы правил не попадают в резюме, заголовок, черновик и перевод. Первая линия при таком ответе передаёт обращение сотруднику, перевод остаётся без машинной версии. Порог изменён решением 0171: восемь слов подряд вместо шести.
4. **Тесты.** `tests/integration/sql-injection.test.ts` (10 тестов: операторы tsquery, метазнаки LIKE, перечни, нулевой байт, инструменты MCP, условия Typesense), `tests/unit/db-no-nul.test.ts`, набор атак AI: категории `hidden_markdown`, `forged_role`, `thanks_injection`, `translation_injection`, `prompt_leak` (93 атаки), `tests/unit/hda-anthropic.test.ts` (в теле запроса нет инструментов).
5. Цена ошибки: перевод решения, в котором честно стоят шесть слов подряд из подсказки переводчика, не будет принят; сотрудник переводит блок сам.
