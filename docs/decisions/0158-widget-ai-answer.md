# 0158. Виджет показывает ответ AI-помощника как ответ AI, а не поддержки

Дата: 28.11.2026. Сверка с ТЗ, волна 7, находка T1 (раздел 8.6, FR-AI-08, UX-B-01..05). Закрывает пункт 6 решения 0088.

1. **Что было.** Проекция обращения для виджета (`GET /api/embed/tickets/{номер}`) сводила автора сообщения к "client" или "support". Ответ AI-помощника клиент видел в виджете с подписью "Поддержка Smartup", без знака Теза, строки "Ответ подготовлен AI" и кнопок.
2. **Проекция.** Сообщение помощника получает автора `ai` и поле `ai` с данными ответа: вступление по идентификатору, заголовок и документ решения из `hdk_published` на языке виджета, пара решений уточняющего вопроса, срок и вопросы передачи, известная проблема, объявление о сбое, признаки `actionable` и `canResolve`. Данные собирает `src/modules/hdt/api/embed-ai.ts` из тех же функций, что страница портала. Текст сообщения помощника и идентификатор решения ответа в проекцию не уходят.
3. **Вид.** `src/ui/widget/TezMessage.tsx`: знак только через `TezMark`, подпись "Тез · AI-ассистент", документ решения через `DocView`, строка "Ответ подготовлен AI по базе решений", кнопки "Помогло", "Не помогло", "Нужен сотрудник" и выбор в уточняющем вопросе. Тексты те же, что у портала (`client.tez` в `messages/*.json`). Вид получает только сообщение с автором `ai`: текст клиента его не получает.
4. **Кнопки.** Действие `ai_feedback` в `POST /api/embed/tickets/{номер}`: токен виджета (`withEmbedRequest`), схема Zod, общая операция `aiFeedback` модуля обращений. Своей логики у виджета нет: права, порядок и запись в историю те же, что у портала и письма.
5. **Почему не сам компонент портала.** `AiMessage` портала серверный: читает сессию портала и отправляет формы серверным действием. Страницы виджета сессию портала не читают (решение 1 плана M6), запросы идут с токеном виджета. Поэтому общий у двух видов состав данных и тексты, а разметку виджет рисует своим клиентским компонентом.
6. Бюджет скриптов виджета проверяется прежним тестом `tests/e2e/budget.spec.ts` и `pnpm budget`.
