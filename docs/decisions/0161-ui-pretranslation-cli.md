# 0161. Команда предварительного перевода нового языка интерфейса

Дата: 28.11.2026. Сверка с ТЗ, волна 7, находка T4 (FR-I18N-10).

1. **Команда.** `hub i18n:pretranslate --to <код> [--name <название>] [--from ru] [--out <файл>] [--glossary glossary.csv] [--force]`. Берёт строки `messages/<from>.json`, переводит их моделью пачками (до 60 строк и 12 000 знаков) по глоссарию терминов Smartup и пишет черновик `messages/<код>.draft.json`. Существующий файл без `--force` не перезаписывается. Клиент модели тот же, что у портала (`getAiClient`): настоящий по ключу `ANTHROPIC_API_KEY`, заглушка при `AI_STUB=1`.
2. **Что уходит в модель.** Только строки интерфейса из `messages` и глоссарий (без колонки примечаний). Это тексты самого портала: данных клиентов, обращений, людей и организаций в них нет, базу команда не читает. Ключи строк и пути файлов не уходят: строка идёт под порядковым номером. Перечень раздела 14.3 ограничивает данные клиентов и переписку; строк интерфейса он не касается, сверх него в модель ничего не уходит. Проверено тестом по телу запроса заглушки.
3. **Проверка ответа.** Номер куска из отправленных; набор подстановок ICU (`{name}`, `{count, plural, ...}`), знак `#` и теги разметки те же, что у исходной строки. Строка, не прошедшая проверку или пропущенная моделью, остаётся на исходном языке, команда печатает её ключ. Устройство файла повторяет исходный: модель не может добавить или убрать ключ.
4. **Чего нет.** Вызов не пишется в журнал `hda_runs`: команда работает без базы, запуск разовый и ручной. Расход виден в кабинете Anthropic. Результат вычитывает человек (требование FR-I18N-10); язык включается отдельно: файл переименовывают и добавляют код в `src/i18n/locales.ts`, `pnpm check` сверяет ключи.
5. Тесты: `tests/unit/hda-ui-translate.test.ts`, `tests/unit/cli.test.ts`.
