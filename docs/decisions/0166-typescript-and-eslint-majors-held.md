# 0166. Мажорные версии typescript и eslint отложены; остальные обновления недели приняты

Дата: 28.11.2026. Волна 7b, поручение координатора после слияния запросов Dependabot в main.

1. **Что случилось.** Недельный запрос Dependabot поднял `typescript` с 5.9.3 до 7.0.2 и `eslint` с 9.39.5 до 10.15.0. Проверка `pnpm check` в main упала: `typescript-eslint` 8.72.2 и `eslint-config-next` 16.4.6 эти версии не поддерживают.
2. **Решение.** `typescript` возвращён на 5.9.3, `eslint` на 9.39.5. В `.github/dependabot.yml` мажорные обновления этих двух пакетов отключены. Переход на новые мажорные версии - отдельная задача: сначала должны выйти совместимые `typescript-eslint` и `eslint-config-next`, затем обновление идёт одним запросом вместе с ними.
3. **Что принято.** `better-auth` и `@better-auth/sso` 1.7.26, `lucide-react` 1.75.0, `@playwright/test` 1.65.1, `rolldown` 1.3.3, `vitest` 5.1.1, образ `caddy` 2.11.9. Модульный тест `tests/unit/project-config.test.ts` закрепляет версии пакетов входа и сборщика: ожидания обновлены на 1.7.26 и 1.3.3 после прогона проверок (числа в `docs/plans/W7b-report.md`).
4. **Браузер Playwright.** Версия 1.65.1 ждёт свою сборку Chromium. Там, где её нельзя скачать, браузерные тесты запускаются с готовым Chromium машины через переменную `PW_CHROMIUM_PATH`. В CI переменная не задана, поведение прежнее.
5. **Поиск секретов.** Срабатывание gitleaks на `NEW_PASSWORD` в `tests/integration/staff-password-change.test.ts` ложное: это пароль, придуманный для теста. Отпечаток добавлен в `.gitleaksignore`.
6. **Цена ошибки.** Без перехода на новые мажорные версии проект остаётся на поддерживаемых ветках обоих пакетов; риск только в том, что переход будет отложен слишком надолго. Напоминанием служит комментарий в `dependabot.yml`.
