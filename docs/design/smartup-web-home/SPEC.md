# Smartup Web - «Главная и навигация»: спецификация для разработки

Прототип: холст «Smartup Web - Tez», страница «2 · Главная и навигация», экраны 3.01-3.21 (версия 92, 14.11.2026). План и решения блока - документ проекта `smartup-web-block3-plan.md`. Каркас (шапка, меню, поиск, уведомления, профиль, состояния) общий для всех разделов, в том числе для «Заказов».

## 3. Правила и решения
| Правило | Значение |
|---|---|
| Главная | Только для роли «Руководитель» (CEO 11.11). Супервайзер, бухгалтер, склад - позже |
| Навигация | 11 разделов сгруппированы в 7: Главное · Продажи · Склад и производство · Финансы и кадры · Оборудование · Справочники · Ещё. Состав групп - предположение, ждёт подтверждения |
| Мегаменю | Слева подразделы группы, справа колонки форм. Нарисованы «Продажи» и «Ещё». Закрытие по Esc и клику вне - предположение, в макетах не показано |
| Показатели главной | Выручка с % плана и прогнозом, валовая прибыль с маржой, дебиторка с просрочкой, АКБ; период Сегодня / Неделя / Месяц |
| План-факт | 95% и выше - зелёный, 90-94% - синий, ниже 90% - оранжевый |
| «Требует внимания» | По важности: одна красная проблема, затем оранжевые; у каждой действие «Открыть» или «Разобрать» |
| Приветствие | 5-11 «Доброе утро», 12-17 «Добрый день», 18-22 «Добрый вечер», 23-4 «Доброй ночи» - как на странице входа |
| Анимация | Каркас 0-0,3 с, блоки с шагом 0,1 с, числа считаются 0,5-2 с, итог в 3,3 с; при «уменьшить движение» всё отключается |
| Тема | Светлая, тёмная, системная - в меню профиля |
| Блокировка | Alt + L; разблокировать паролем; Alt + L + L - на страницу входа |
| Демо-данные | План месяца 600 млн (20 млн в день); на 10.11 факт 186,5 млн = 93%; прогноз 186,5 / 10 × 30 = 560 млн; дебиторка 142,8 млн, больше 30 дней - 15,7 млн (11%) |

## 4. Адаптивность
Каркас уже частично перестраивался (правила 1360 / 1200 / 900 / 560 в `shell.css`): меню сворачивалось в «Разделы», карточки главной вставали по две и по одной. **Не было**: мегаменю, поиска, меню шапки, окна блокировки и страницы списка на узких экранах - они уходили за край. **Добавлено при подготовке поставки** (предложение) - слой `.ws.fluid` в `prototype/assets/shell.css`, разметка экранов не менялась.

| Ширина / окно | Раскладка |
|---|---|
| от 1600 | Главная не шире 1680 px по центру; страницы списков - на всю ширину |
| 1440 | Как на холсте |
| 1280-1439 | Пункты меню компактнее; мегаменю по ширине окна, колонки переносятся; таблица страницы списка прокручивается внутри рамки |
| от 1280, окно 860 px и ниже | Прокручивается страница, шапка закреплена |
| 1200 и уже | 7 групп сворачиваются в кнопку «Разделы» |
| 1024-1279 | Поиск и окно блокировки - по центру окна |
| 600-1023 | Мегаменю - под шапкой на всю ширину; строки страницы списка - в две линии (клиент, сумма, статус / зона, штат, даты, валюта); каркас загрузки перестраивается |

| до 360 | В шапке скрыт переключатель приложений (остаётся в профиле) |

Проверено: ширины и окна 320, 360, 390, 768, 1024, 1100, 1280×720, 1366×768, 1536×864, 1920×1080 - ничего не выходит за край страницы; на 1440×900 статичная вёрстка совпадает с холстом пиксель в пиксель на всех 19 экранах; телефон и планшет - глазами по снимкам. Доски холста при 1440×900 ошибок вёрстки не имеют.

## 6. Вид
- **Шрифт:** Montserrat 400/500/600/700. **Цвета:** `angular/styles/_tokens.scss`. **Шапка:** тёмная в обеих темах, 52 px.
- **Иконки:** линейные, 24 px, толщина 2. **Тез:** плоский, без глаз и лица, синее крыло слева, не отражается зеркально.
- **Красный** - только для ошибок и красной проблемы в «Требует внимания», не для элементов бренда. **Логотип:** знак + «smartup», без подложки; живой логотип - страница холста «4 · Живой логотип».
- **Доступность:** в прототипе часть кнопок - `span` с `role`; в продукте - настоящие `<button>`, видимый фокус, Esc закрывает меню и окна. Контраст отдельно не проверялся.

## 7. Что не переносить в продукт
- Демо-данные: суммы, регионы, клиенты, люди, организации «Демо Самарканд», «Демо Фергана».
- Вёрстка `prototype/` - образец вида: логики, проверок и безопасности нет; ссылки на страницу входа отключены, ссылки внутри блока работают.
- Две формы «Заказы» в мегаменю (текущая и NEW) - до решения, какая остаётся.
