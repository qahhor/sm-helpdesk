# Вычитка переводов

Тексты интерфейса пишутся на русском. Узбекский и английский варианты готовит разработка как черновик, затем их вычитывает человек, владеющий языком и словарём бренда (`glossary.csv`).

| Язык | Пространства | Состояние | Кто вычитал | Дата |
|---|---|---|---|---|
| ru | common, client, agent | эталон | | |
| uz | common, client, agent | ждёт вычитки | | |
| en | common, client, agent | ждёт вычитки | | |

Что проверить при вычитке узбекского текста:

- латиница, прямой апостроф в `o'` и `g'`;
- нет слова "dala" ни в какой форме;
- термины совпадают со словарём;
- кнопки и заголовки помещаются: узбекский текст длиннее русского на 20-30%.
