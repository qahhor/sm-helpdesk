| 6 | Обращение у сотрудника | Переписка с заметками и историей, отметка нового с прошлого визита, карточка клиента, сроки, просмотр картинок и PDF. Клиенту адрес рабочего места отвечает "не найдено" |
| 7 | Действия сотрудника | Взять себе (двое одновременно: взял один), исполнитель, статус по таблице 7.2 с итогом и версией, приоритет с причиной, тип, модуль, отложить. Событие и журнал в той же транзакции |
| 8 | Ответ и заметка | Два режима поля разного цвета, первый ответ останавливает срок первого ответа и берёт новое обращение, "Ждём ответа клиента" одним действием, предупреждение "пока вы писали, обращение изменилось" с выбором, черновик на сервере, присутствие, упоминания, файлы сотрудника через тот же карантин. Клиент видит "Поддержка Smartup" |

| 10 | Шаблоны ответов | Код после "/", текст на трёх языках, модуль. В поле ответа список по "/", вставка на языке обращения, без перевода русский с отметкой |
| 11 | Объединение и массовые действия | Дубль закрывается со ссылкой на конечное основное, клиент видит номер основного, только если видит основное, открыть объединённое нельзя. Массово: назначить, передать на вторую линию с одной запиской, вернуть, закрыть как дубль, итог по каждому |

### Критерии готовности (строка M3 раздела 16.2)

1. Сценарий S3 проходит: `tests/e2e/agent.spec.ts`, тест "приёмка M3, сценарий S3". Очередь по сроку, взять, приоритет с причиной, заметка, ответ с "Ждём ответа клиента" и паузой срока, ответ клиента на портале возвращает обращение в работу, пауза учтена. Там же: axe без серьёзных замечаний на очереди и обращении, без прокрутки вбок на ширине ноутбука при масштабе 200%. Отдельно с клавиатуры без мыши: "цикл S3 с клавиатуры без мыши".
2. Все случаи таблицы 11.7 покрыты тестами: `tests/unit/sla.test.ts` (девять случаев таблицы один к одному, пауза 2 рабочих часа, создание в праздник, пауза через выходной и праздник, независимость от часового пояса процесса), `tests/integration/ticket-sla.test.ts` (сроки при создании, смена приоритета P3 на P1 от момента создания, пауза "Ждём вашего ответа", выход из паузы ответом клиента, смена календаря не двигает назначенные сроки), `tests/integration/housekeeping.test.ts` (нарушения один раз, автозакрытие по рабочим дням).
3. Запрещённый переход статуса отклоняется: `tests/unit/hdt-transitions.test.ts` (ровно 13 переходов 7.2), `tests/integration/agent-actions.test.ts` (`transition_refused`, "В разработке" только второй линии).
4. Передача на вторую линию без записки невозможна: `tests/integration/lines.test.ts` (сервис отвечает `invalid_input`, база не принимает строку без причины, проверенного и требуемого), браузерный тест "передача на вторую линию: кнопка неактивна без трёх полей", массовая передача требует ту же записку (`merge.test.ts`).

## Что отложено

- Уведомления: упоминание, нарушение срока руководителю линии, P1 дежурным, отложенное вернулось, напоминание клиенту через 3 рабочих дня (FR-AG-16, FR-SLA-06, 07, 09, FR-TK-15): M4 по событиям M3.
- Очередь "Неопознанные" и ответ письмом: M4.
- Похожие обращения и решения в карточке: M5. Перевод сообщения, блок AI, очередь "После AI": M5b.
- Привязка к известной проблеме в массовых действиях: M5c.
- Поле срока "взять в работу" на экране настроек: значение читается из настройки `lines.pickup_minutes`, экрана для неё пока нет.
- Подсказка имён при вводе "@" в заметке и подтверждение приоритета из палитры.
