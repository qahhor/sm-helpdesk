## Независимая проверка

Два проверяющих. Найдено одно критичное и восемь важных замечаний, все исправлены с тестами, которые сначала падали (решение 0057):
- **критичное:** публикация и автосохранение из второй вкладки могли разойтись: клиент видел проверенный текст, а история версий хранила непроверенный, с телефоном. Теперь сохранения и публикации одного решения идут по очереди;
- **данные для Claude:** цитаты пересланных писем уходили в модель; маскировку телефонов и адресов обходили полноширинные и арабские цифры, знак `＠`, разделители `/` и `.`; название организации маскировалось только точным совпадением. Закрыто;
- задание переиндексации терялось, если приходило во время предыдущего; повторы при сбое Claude не работали; несохранённый текст без связи мог пропасть при перезагрузке; восстановление из архива не возвращало переводы; счётчик подсказки недосчитывал "Помогло".

## Что ждёт владельца

| Материал | Что откроет |
|---|---|
| 50-100 текстов ошибок Smartup | Подстройка сигнатур (`hub signatures:test`) |
| Доступ к huggingface.co | Настоящие векторы BGE-M3, проверка контейнера TEI |
| 90 запросов с ответами (по 30 на трёх языках) и около 30 решений | Замер качества поиска по 15.4 (`pnpm eval:search`) |
| Ключ Anthropic API и доступ к api.anthropic.com | Настоящие черновики и переводы; первый вызов проверяет формат запроса и цены |
| Память сервера: 16 ГБ или урезанные пределы | Контейнер TEI: с ним сумма пределов около 9,8 ГБ при 8 ГБ |
| Список разрешённых доменов для ссылок в решениях | Публикация решений с внешними ссылками |

## Не проверено

- Настоящие API Anthropic и TEI.
- Качество поиска на узбекском.
- Вставка снимка из системного буфера и из настоящего Word на Windows и macOS, разметка и перетаскивание на сенсорном экране, Firefox и Safari.

## Отклонения, записанные в решениях

- Ссылки в решениях только `https` и внутренние, `mailto` не разрешён (0047).
- Машинный перевод, прошедший сверку с оригиналом, публикует сотрудник с правом публикации без отметки "Текст прочитан" (решение 9 плана).
- Черновик делается из решённого или закрытого обращения (решение 15 плана; в 14.3 сказано "закрытого").
- Замечания AI к тексту (UX-W-08) заменены проверками кода (решение 14 плана).
- Запрос из одного слова не ищется; поля формы не сворачиваются, если клиент уже начал их заполнять (0054).
- Модуль не входит в сигнатуру с портала (0055).
