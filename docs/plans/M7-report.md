## Независимая проверка

Критичных замечаний нет. Исправлено с тестами (решение 0065):
- счётчики голосов и возврат идей из короткого списка больше не переключают триггер на системного пользователя: это делает узкая роль без входа `hub_hdi_counter` через функции, которые пересчитывают голоса по настоящим строкам. Обхода защиты строк больше нет, согласие владельца не нужно;
- при объединении дублей голос, отданный в ту же секунду, больше не теряется;
- сотрудник `product` прямым запросом не может добавить или удалить голос клиента, создать задачу разработки в закрытом статусе, переписать текст опубликованной идеи;
- в письмах только оригинал или проверенный перевод названия; объяснение выбора, сохранённое без правки машинного черновика, клиент видит с пометкой "Машинный перевод";
- браузерные тесты больше не оставляют данных в общей тестовой базе.

## Перед выкладкой на сервер

Миграция 0084 требует роль `hub_hdi_counter`: перед её применением заново запустить начальную настройку базы (`docs/runbooks/launch.md`). Без роли миграция останавливается с понятным сообщением и ничего не меняет.

## Не проверено

- Настоящий машинный перевод идей и поиск по смыслу.
- Передача идеи в настоящий таск-менеджер Smartup.
- Проверка удобства на живых людях (M9).
- Lighthouse для доски идей: инструмент измеряет только страницы без входа; доску покрывает бюджет скриптов.

## Решения, на которые стоит посмотреть

- Идеи видят клиенты всех организаций; отклонённую видят автор и, если она успела побыть на доске, проголосовавшие и подписчики (решение 2 плана).
- Автор голосует за свою идею автоматически (4).
- Комментарий с телефоном, email, ИНН, адресом сервера или ссылкой ждёт модератора (8).
- Имена голосовавших не видит никто, включая сотрудников (24).
- В отбор попадают только идеи хотя бы с одним голосом; невыбранный отбор закрывается к следующему 1-му числу (16, 17).
- Посетители без входа идей не видят (21).
