# Отчёт по вехе M8b "Сервер MCP и AI-сотрудник"

Дата: 27.11.2026. Ветка `claude/smartup-customer-portal-iszbit`. План `docs/plans/M8b.md` подтверждён общим поручением владельца 26.11.2026; решения 3 и 7 плана изменены решениями владельца 27.11.2026. Решения вехи: `docs/decisions/0110`-`0121`. Журнал исполнителя: `.superpowers/sdd/M8b/progress.md`.

## Итог

Внутренний агент (Hermes Agent, позже другие) подключается к порталу через сервер MCP `POST /api/mcp` по токену с перечнем инструментов, сроком, списком адресов и суточным пределом. Протокол разбирает свой обработчик JSON-RPC 2.0 без новой зависимости (решение владельца, 0110). Агент читает обезличенные обращения организаций с включённой AI-обработкой, внутренние заметки сотрудников в обезличенном виде (решение владельца, 0114), решения, кандидатов, известные проблемы, идеи, сигнатуры, всплески и показатели помощника; текст людей приходит только в полях `untrusted_*`. Пишет агент только то, что видят сотрудники: внутреннюю заметку, записку второй линии, черновик решения, черновик известной проблемы, сводку; каждая запись помечена "AI-сотрудник, не проверено", клиент её не видит. Каждый вызов записан в журнал вызовов без аргументов, вызов вне перечня отклонён и записан в журнал аудита, отзыв токена действует со следующего запроса. Портал сам находит всплеск сигнатуры и отправляет агенту подписанные события с токеном запуска на одно обращение.

Всё проверено тестовым клиентом MCP и заглушкой приёмника событий. С настоящим Hermes Agent ничего не проверено: профиля, адреса и секрета приёма событий нет.

## Долги и что не проверено

- Страница обращения сотрудника на ширине 360 шире окна и без записей агента (обращение с неподтверждённым приоритетом): находка вне вехи, предложена отдельной задачей; браузерный тест пометок проверяет эту страницу на 768 и 1280.
- Имена людей не из организации обращения и не сотрудников обезличивание не узнаёт; тексты решений, кандидатов, идей и проблем обезличиваются общими правилами без списка имён (решение 0115).
- Похожие обращения без расширения `pg_trgm`: та же сигнатура, затем тот же модуль с общими словами темы.
- Минутный и суточный пределы считают только `tools/call`; события уходят с задержкой до минуты.
- Порядок "сначала увидеть падение" нарушен для части тестов (журнал, строки `Ruling` задач 4, 6, 10): интеграционный `hda-mcp-server`, модульный `hda-team-chat`, интеграционный `hda-digests` написаны до кода, но первый запуск был после кода; браузерные `agent-bot-marks`, `agent-digests`, `agent-mcp-s19` запускались только в задаче 11 (база браузерных тестов постоянная, миграции применялись туда после готовности всех миграций вехи).
- Долги M5b и M5c (раздел "Не входит в M8b" плана) остаются с прежними причинами.
