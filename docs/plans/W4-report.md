## Что нашла независимая проверка и что нашёл первый запуск CI

Проверка ветки: правило о шаблонах поиска было слабым (ловило не все записи), отметка оператора не переживает восстановление из дампа, выгрузка могла потерять запись долгой транзакции, одно правило хранения бакета стёрло бы копии журнала. Всё исправлено; перечень в решении 0041, пункт 8.

Первый запуск GitHub Actions с вехи M0 нашёл четыре расхождения между CI и машиной разработчика, все в задаче браузерных тестов:
- настройка тестов в CI ждала базу и ключи от самой задачи; теперь путь один;
- четыре снимка витрины расходились с эталоном на 2%: на машине CI системные настройки шрифтов рисуют буквы с хинтингом. Браузер тестов теперь запускается без хинтинга и без сглаживания по субпикселям на любой машине; эталоны не менялись;
- замеры бюджета и Lighthouse читают базу разработки, а её в CI никто не готовил;
- один холодный замер Lighthouse на общей машине CI дал 83 при пороге 85 (локально 97). Оценка теперь берётся как медиана трёх замеров; пороги ТЗ не менялись.
