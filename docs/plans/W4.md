## На что смотреть проверяющему

1. `LEAKPROOF`: может ли клиент через поиск узнать что-либо о строках, которых не видит (ошибки, время ответа).
2. Удаление журнала аудита: нельзя удалить запись моложе 3 лет никаким актором.
3. Выгрузка журнала: открытый текст не остаётся на диске, сбой не теряет сутки.
4. `undici`: проверка адреса действует на все запросы библиотеки входа, а не на часть.
