## Независимая проверка

Критичных замечаний нет. Важное одно: подтверждение приоритета без смены пробный прогон считал сменой приоритета, а настоящее правило на нём не срабатывает. Исправлено, случай добавлен в тест равенства пробного прогона и срабатываний (сначала падал).

Оставлено, с ценой:
- пробный прогон предустановленного правила недосчитывает события, порождённые правилами и макросами (их встроенные уведомления обрабатывают, история этого не различает);
- событие "срок скоро" в пробном прогоне восстанавливается по срокам и не учитывает паузу ожидания клиента;
- макрос защищён от старой страницы до первого действия; смена очереди, тегов и отложить посреди макроса версию не проверяют;
- проверка старой страницы не обязательна для вызывающего кода: страница передаёт версию всегда, обход снимает защиту только с самого сотрудника.
