### Task 1 (Задача 1)
- [x] Браузерный тест: на ширине 360 px ни одна страница рабочего места не прокручивается вбок, включая верхнюю панель. Исправление в оболочке (`src/ui/shell/agent/`), только токенами.

### Task 2 (Задача 2)
- [x] Пробный прогон берёт из последних 100 обращений те, у которых было событие вида правила (по истории событий обращения, `hdc_domain_events` хранится 30 суток: старше смотреть по истории обращения), и проверяет условия на текущем состоянии. Для "нет активности": обращения, которые молчат дольше заданных часов, с учётом статусов, как у настоящего просмотра. Страница говорит, по какому признаку отобраны обращения. Тест: число совпадений пробного прогона равно числу настоящих срабатываний на подготовленном наборе.

### Task 3 (Задача 3)
- [x] Меню макросов передаёт версию страницы обращения; если обращение изменили другие, макрос не выполняется и страница называет изменения (как действия статуса, исполнителя и приоритета, решение 0040). Тест на старую страницу.
