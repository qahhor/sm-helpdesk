# Волна 7b "Исправления по проверкам качества и интерфейса": план

**Цель:** закрыть находки двух проверок: (1) качество решения (Q1-Q23), (2) интерфейс и удобство (U1-U28, страница `/legal/privacy`).

**Источник:** поручение владельца от 28.11.2026, второй проход после волны 7 (`docs/plans/W7.md`).

## Общие ограничения

Правила `CLAUDE.md`. Для каждой находки сначала падающий тест, потом код. Новых пакетов и внешних сервисов нет. Политики RLS и тесты изоляции не ослабляются. Применённые миграции не правятся: новые с номера 0134. Решения с номера 0163. Строки интерфейса только в `messages/*.json` на трёх языках. Размеры и цвета только токенами. `docs/TZ.md` не правится. Находки интерфейса проверяются снимком в браузере.

## Порядок

1. Критичное: U1.
2. Важное: Q1-Q10, U3-U16.
3. Мелкое: Q11, Q12, Q14-Q18, Q20-Q22, U17-U28, `/legal/privacy`.

Мелкая находка, которая по сути косметика с риском поломок, может быть отложена с записью в отчёте.

## Часть 2. Качество

| № | Находка | Что делаем |
|---|---|---|
| Q1 | Рассылка по проблеме зависает | Обход зависших рассылок в минутной задаче, отказ одного получателя не роняет остальных, сигнал |
| Q2 | Транзакция записи ждёт пул входа | Чтение ролей, привязок и названий до транзакции |
| Q3 | Настройки читаются по одной транзакции на значение | `readSettings(codes)` одной выборкой |
| Q4 | Отправка событий AI-сотруднику без бюджета | Бюджет 50 с, остановка на неответившем адресе, порядок шагов, отзыв прежнего токена |
| Q5 | Нет обхода зависших проверок файлов решений и идей | Обход по образцу вложений обращений |
| Q6-Q8 | Хрупкие браузерные тесты | Свои данные, поиск по уникальному признаку, без молчаливых пропусков |
| Q9 | Тесты планов зависят от статистики | `autovacuum=off` и явный `ANALYZE` в помощнике |
| Q10 | Пороги по стенным часам | Перенос в проект `perf` |
| Q11, Q12 | Вложенные транзакции внутри `withActor` | Чтение до транзакции; правило проверки |
| Q14 | Смена статуса рассылкой без события | `emitEventTx('status_changed')` |
| Q15 | Номер события Telegram пишется до обработки | Запись вместе с обработкой |
| Q16 | Проглоченные ошибки | Ловить только свой код ошибки |
| Q17 | Ночная очистка одним шагом | `runJobSteps` |
| Q18 | Полная переиндексация внутри `search.sync` | Отдельная задача |
| Q21 | N+1 в приёме писем | Одна выборка |
| Q22 | Задачи pg-boss между тестами | Очистка `pgboss.job` |
| Q13, Q19, Q23 | Крупные переделки | Не делаем, долг в отчёте |
