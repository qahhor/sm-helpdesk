# Staging после вехи M1: памятка перенесена

С 22.11.2026 все шаги настройки и запуска собраны в одном документе: [launch.md](launch.md). Он подходит и для staging, и для production, пункты оформлены списком для отметки.

Где теперь прежние пункты этой памятки:

| Прежний пункт | Раздел в launch.md |
|---|---|
| 1. Переменные окружения, бакет R2, ClamAV, файлы рядом с `compose.prod.yaml` | 3 (R2), 8 (файлы и секреты) |
| 1б. Cloudflare перед порталом | 2 (Cloudflare), 11 (решение о Bot Fight Mode) |
| 1a, шаги 1-5. Первый запуск | 9 |
| 1a, шаги 5a и 5б. Проверка вложений и заголовков R2 | 11, "Файлы и антивирус" |
| 1a, шаг 6. Ночная очистка | 14 |
| 1a, шаги 7-9. Веха M3: сроки, задача раз в минуту, рабочее место | 10 (сроки и праздники, шаблоны, памятки), 9 (расписания), 11 ("Рабочее место"), 14 |
| 2. Команды hub по порядку | 10 |
| 3. Как проверить каждый способ входа | 11, "Вход" |
| 4. Что известно заранее | 14 |

Отчёты вех (`docs/plans/M<n>-report.md`) ссылаются на пункты этой памятки по прежним номерам: таблица выше переводит их в разделы launch.md. Новые шаги дописываются только в launch.md.
