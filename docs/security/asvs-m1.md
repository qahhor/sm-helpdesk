# Проверки ASVS для вех M0 и M1

Дата: 21.11.2026. Основание: раздел 15 ТЗ (приёмка по OWASP ASVS 5.0, уровень 2) и пункт C8 плана `docs/plans/M1-hardening.md`. Полный чек-лист проходится в M9. Здесь то, что уже построено во входе и личности, по главам стандарта, с тестом или файлом, который это подтверждает. Номера отдельных требований сверяются с текстом стандарта при приёмке M9.

Состояние: "есть" значит сделано и проверяется тестом; "частично" значит сделана часть, остальное в названной вехе; "M9" значит ещё не начато.

## Известные отклонения

- Посетитель с заблокированным `challenges.cloudflare.com` не пройдёт проверку "не робот" на формах без входа (решение 0018).
- Строки с хешами одноразовых ссылок не удаляются до ночной задачи M2 (решение 0023).
- CSP до M9 работает в режиме отчётов (решение 0010).
