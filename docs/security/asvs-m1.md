## Известные отклонения

- Посетитель с заблокированным `challenges.cloudflare.com` не пройдёт проверку "не робот" на формах без входа (решение 0018).
- Строки с хешами одноразовых ссылок удаляет ночная задача M2 (решение 0023, дополнение M2).
- Тесты протокола ClamAV идут против ложного сервера; с настоящим ClamAV вложения проверяются на staging (памятка, шаг 5a).
- CSP до M9 работает в режиме отчётов (решение 0010).
- Ответы сотрудников не ограничены по частоте: сессия сотрудника со вторым фактором, пределы раздела 14.5 заданы для клиентов (решение 0031, пункт 8; журнал M3).
